> **في ٢٠٢٦: س٢ بند «عقد الاهتزاز في موجة مستقرة» (٢٠ درجة، اختياري).** المصادر: الكتاب ص ١٦٨–١٨١ · الأستاذ فداء «الأمواج» (س١–س٩ + طرق حل مسألة الوتر ١–٨ + مسائل ص ١٩٤–١٩٥، ٢٧٩–٢٨٠). الرموز: `λ` طول الموجة (m)، `f` التواتر (Hz)، `T` الدور، `v` سرعة الانتشار (m·s⁻¹)، `a` سعة المنبع، `A` سعة نقطة، `x` بعد النقطة عن النهاية المقيدة، `L` طول الوتر، `n` عدد المغازل/رتبة المدروج، `FT` قوة الشد (N)، `μ` الكتلة الخطية (kg·m⁻¹)، `ρ` الكتلة الحجمية، `S` مساحة المقطع.

## 🔑 قبل أن تبدأ
**تحتاج:** التابع الجيبي `y = a·cos(ωt + φ)` (U1/L1)، `λ = v·T = v/f`، تحويل مجموع جيبين إلى جداء: `cos p + cos q = 2·cos((p+q)/2)·cos((p−q)/2)`، `sin p + sin q = 2 sin((p+q)/2) cos((p−q)/2)`.

**سؤال توقّع:**
> وتر مشدود بين نقطتين يهتز بمغزلين. (أ) كم عقدة وكم بطناً؟ (ب) لو زدنا قوة الشد — يزداد عدد المغازل أم ينقص؟ (ج) هل تنتقل الطاقة على طول الوتر في الموجة المستقرة؟

## 📖 الفكرة

### ١. تذكير: الموجة، العرضية والطولية [أستاذ]
**الموجة:** مؤثر أو اضطراب يسبب انتشاره تغيراً **مؤقتاً** في بعض المقادير الفيزيائية المميزة لوسط ما.
- **عرضية:** منحى انزياح المادة **عمودي** على منحى الانتشار (وتر مشدود، سطح سائل).
- **طولية:** منحى الانزياح **منطبق** على منحى الانتشار (تخلخلات وانضغاطات في نابض، الصوت).
**طول الموجة `λ`:** المسافة التي يقطعها الاهتزاز خلال دور واحد: `λ = v·T = v/f`.

### ٢. الانعكاس عند النهاية [أستاذ / الكتاب ص ١٧٠]
تنعكس الإشارة **بالسرعة نفسها والتواتر نفسه والسعة نفسها** (بإهمال ضياع الطاقة)، وينشأ فرق طور بين الواردة والمنعكسة:
- **نهاية مقيدة (ثابتة):** جهة الإشارة المنعكسة **تعاكس** الواردة ⇒ **تعاكس بالطور** (`π`). **لماذا؟** الحامل الثابت يرد على الوتر بقوة معاكسة (الفعل ورد الفعل) فيقلب الإشارة.
- **نهاية طليقة (حرة):** الجهة **نفسها** ⇒ **توافق بالطور**.

### ٣. الموجة المستقرة — التعريف والوصف [أستاذ س١ / الكتاب ص ١٧٢]
**الموجة المستقرة:** نمط اهتزاز مستقر يحتوي على **عقد بينها بطون**، ينشأ نتيجة **التداخل بين موجتين متساويتين في التواتر والسعة تنتشران في اتجاهين متعاكسين**.
**كيف نحصل عليها (تجربة ملد):** عندما تعمل الرنانة ينتشر الاهتزاز العرضي على طول الوتر حتى نهايته المقيدة فينعكس عنها؛ تتداخل الواردة مع المنعكسة (نفس `f` و`a`، جهتان متعاكستان) فتتشكل الأمواج المستقرة العرضية.
- **بطون الاهتزاز `A`:** نقاط تهتز بسعة **عظمى** — تلتقي فيها الواردة والمنعكسة على **توافق دائم**.
- **عقد الاهتزاز `N`:** نقاط سعتها **معدومة** (ساكنة) — تلتقي فيها على **تعاكس دائم**.
- بين كل عقدتين متجاورتين **مغزل**؛ **نقاط المغزل الواحد على توافق بالطور**، ونقاط **مغزلين متجاورين على تعاكس بالطور** ⇒ تبدو الموجة تهتز **مراوحة في مكانها** بشكل ثابت — ومن هنا «مستقرة».
- **[أستاذ ثانياً ص ١٩٤]** لماذا لا تنقل طاقة؟ لأن الواردة والمنعكسة تنقلان الطاقة باتجاهين متعاكسين (جواب سؤال التوقّع ج: **لا**). لماذا تبدو ساكنة؟ لأن النقاط تهتز مراوحة مكانها فتأخذ شكلاً ثابتاً.

**المسافات الذهبية:**
| بين | المسافة |
|---|---|
| عقدتين متجاورتين، بطنين متجاورين، طول المغزل | **`λ/2`** |
| عقدة وبطن يليها مباشرة | **`λ/4`** |

> **⚠️ الخطأ الشائع ١:** «طول المغزل = `λ`». المغزل **نصف** طول موجة. في سؤال «قِس المسافة بين عقدتين متتاليتين، ماذا تمثل؟» الجواب `λ/2` — وخلط هذا يضاعف/ينصّف كل النتائج التالية.

## 🧮 البرهان المُرقَّم ١ — مطال نقطة من موجة مستقرة (نهاية مقيدة) [أستاذ س٢ / الكتاب ص ١٧٢–١٧٣]
مبدأ الإحداثيات عند النهاية المقيدة `O`؛ النقطة `n` على بعد `x` منها؛ الموجة الواردة تنتشر باتجاه `−x` (نحو `O`) والمنعكسة باتجاه `+x`. نأخذ الطور عند `O` مرجعاً.
| # | | درجة |
|---|---|---|
| ① | الواردة تصل `n` قبل `O` بزمن `x/v` ⇒ `y1 = a·cos(ω(t + x/v)) = a·cos(ωt + 2πx/λ)` | ٤ |
| ② | المنعكسة تنعكس بتعاكس (`π`) عند `O` ثم تعود إلى `n` بعد `x/v` ⇒ `y2 = a·cos(ω(t − x/v) + π) = −a·cos(ωt − 2πx/λ)` | ٤ (`π` −١) |
| ③ | المطال المحصّل: `y = y1 + y2 = a[cos(ωt + 2πx/λ) − cos(ωt − 2πx/λ)]` | ٣ |
| ④ | `cos p − cos q = −2 sin((p+q)/2)·sin((p−q)/2)` ⇒ `y = −2a·sin(ωt)·sin(2πx/λ)` | ٤ |
| ⑤ | نكتب `y = A·sin(ωt + π)` (أو ما يكافئه) حيث **`A = 2a·|sin(2πx/λ)|`** — **سعة اهتزاز النقطة `n`** تتعلق بـ`x` فقط | ٥ |

> **التفسير:** كل نقطة تهتز جيبياً **بالتواتر نفسه** لكن **بسعة تعتمد على موضعها**: هذه هي بصمة الموجة المستقرة (خلافاً للمتقدمة حيث السعة واحدة والطور يتغير).

## 🧮 البرهان المُرقَّم ٢ — أبعاد العقد والبطون (**س٢ ٢٠٢٦ = ٢٠**) [أستاذ س٣ / الكتاب ص ١٧٣–١٧٤]
| # | | درجة |
|---|---|---|
| **العقد** | | |
| ① | تعريف: نقاط ساكنة سعتها معدومة، تلتقي فيها الواردة والمنعكسة على تعاكس دائم | ٤ |
| ② | `A = 0 ⇒ sin(2πx/λ) = 0 ⇒ 2πx/λ = kπ` | ٣ |
| ③ | **`xN = k·λ/2`**، `k = 0, 1, 2, …` — أبعاد العقد أعداد **صحيحة** من **نصف** طول الموجة (`0, λ/2, λ, 3λ/2, …`) — النهاية المقيدة نفسها عقدة | ٣ |
| **البطون** | | |
| ④ | تعريف: نقاط تهتز بسعة عظمى `2a`، تلتقي فيها على توافق دائم | ٤ |
| ⑤ | `A = 2a ⇒ |sin(2πx/λ)| = 1 ⇒ 2πx/λ = (2k+1)·π/2` | ٣ |
| ⑥ | **`xA = (2k+1)·λ/4`**، `k = 0, 1, 2, …` — أبعاد البطون أعداد **فردية** من **ربع** طول الموجة (`λ/4, 3λ/4, 5λ/4, …`) | ٣ |

**[أستاذ]** البطن الأول `λ/4`، الثاني `3λ/4`، الثالث `5λ/4`. **نهاية طليقة:** تنقلب الأدوار — البطون عند `kλ/2` والعقد عند `(2k+1)λ/4`.

### ٤. الاهتزازات الحرة في وتر مرن [أستاذ / الكتاب ص ١٧٤]
- نزيح الوتر من **منتصفه** ونتركه ⇒ يهتز بتواتره الخاص `f1` بمغزل واحد ⇒ **الصوت الأساسي**.
- ننقره من **ربعه** ونلمس **منتصفه** ⇒ مغزلان (`f2 = 2f1`).
- ننقره من **سدسه** ونلمس **ثلثه** ⇒ ثلاثة مغازل (`f3 = 3f1`).
الأصوات الناتجة بعد الأساسي تسمى **المدروجات (التوافقيات)**.

### ٥. الاهتزازات القسرية — تجربة ملد على نهاية مقيدة [أستاذ س٤ / الكتاب ص ١٧٦–١٧٨]
وتر تواتر صوته الأساسي `f1`، مثبت طرفه برنانة تواترها `f` قابل للتغيير من الصفر:
| تواتر الرنانة | ما يحدث |
|---|---|
| `f < f1` | اهتزازات قسرية؛ مغزل واحد **غير واضح**، سعة صغيرة |
| **`f = f1`** | مغزل واحد **واضح**، سعة عظمى — **تجاوب** |
| `f1 < f < 2f1` | مغزلان غير واضحين، سعة صغيرة |
| **`f = 2f1`** | موجة مستقرة بمغزلين، سعة عظمى — **تجاوب** |
**النتائج:** ① تتولد أمواج مهما كان `f` ② إذا لم يكن `f` مضاعفاً صحيحاً لـ`f1` ⇒ قسرية بسعة صغيرة ③ **يحدث التجاوب إذا:** تواتر الهزازة = مضاعف صحيح للتواتر الأساسي **أو** (بالتكافؤ) طول الوتر = عدد صحيح من `λ/2`. الوتر **مجاوب متعدد التواتر**.

## 🧮 البرهان المُرقَّم ٣ — تواتر الوتر (نهاية مقيدة) ومدروجاته [أستاذ س٥ / الكتاب ص ١٧٧]
| # | | درجة |
|---|---|---|
| ① | النهايتان عقدتان ⇒ طول الوتر عدد صحيح من `λ/2`: `L = n·λ/2` | ٤ |
| ② | `λ = v/f` ⇒ `L = n·v/(2f)` | ٣ |
| ③ | **`fn = n·v/(2L)`**، `n = 1, 2, 3, …` عدد المغازل = رتبة المدروج | ٤ |
| ④ | `f1 = v/2L` الأساسي (المدروج ١) · `f2 = 2f1` (٢) · `f3 = 3f1` (٣) — الوتر المقيد **يصدر كل المدروجات** | ٣ |

**نهاية طليقة [أستاذ س٦]:** عقدة عند المثبت وبطن عند الطرف الحر ⇒ `L = (2n−1)·λ/4` ⇒ **`f = (2n−1)·v/(4L)`** ⇒ `f1 = v/4L`، ثم `3f1`، `5f1` — **المدروجات الفردية فقط**؛ كل نصف مغزل مدروج.

### ٦. سرعة الانتشار في الوتر [أستاذ س٧ / الكتاب ص ١٧٩]
**الوتر المشدود:** جسم صلب مرن أسطواني طوله كبير بالنسبة لنصف قطر مقطعه، مشدود بين نقطتين ثابتتين تؤلفان عقدتين.
> **`v = √(FT/μ)`** — تتناسب **طرداً مع جذر قوة الشد** و**عكساً مع جذر الكتلة الخطية**.
`μ = m/L` (kg·m⁻¹)؛ العلاقة بالكتلة الحجمية: `m = ρ·V = ρ·S·L` ⇒ **`μ = ρ·S = ρ·π·r²`**.
⇒ **`fn = (n/2L)·√(FT/μ)`**.
**[أستاذ]** يزداد عدد المغازل (بتواتر ثابت) عندما **يزداد `L`** أو **يزداد `f`**، و**ينقص بزيادة قوة الشد** (لأن `v↑ ⇒ λ = v/f ↑ ⇒ n = 2L/λ ↓`). جواب سؤال التوقّع (ب): **ينقص**؛ (أ) مغزلان ⇒ ٣ عقد وبطنان.
**[أستاذ ٢٩ ص ٢٧٩]** `μ` **لا تتغير بتغير طول الوتر** مهما قسمناه — الوتر المتجانس كتلته موزعة بانتظام.

> **⚠️ الخطأ الشائع ٢:** «زيادة الشد تزيد المغازل لأن الوتر يصير أقوى». العكس: الشد يرفع `v`، وبتواتر الرنانة الثابت يطول `λ` فتقل المغازل. لزيادة المغازل **ننقص الشد**.

### ٧. شروط الطور بين نقطتين (فرق المسير) [أستاذ ثانياً ص ١٩٤]
| العلاقة | فرق المسير `Δ` |
|---|---|
| توافق | `Δ = kλ` (أعداد صحيحة من `λ`) |
| تعاكس | `(2k+1)·λ/2` (فردية من `λ/2`) |
| ترابع | `(2k+1)·λ/4` (فردية من `λ/4`) |
البطن الأول والثالث على توافق (`Δ = λ`)؛ البطن الأول والثاني على تعاكس (`Δ = λ/2`).

### ٨. الأمواج المستقرة الكهرطيسية [أستاذ س٨–س٩ / الكتاب ص ١٨٠]
- الموجة الكهرطيسية المستوية: **حقلان متعامدان** كهربائي `E⃗` ومغناطيسي `B⃗` (وكلاهما عمودي على منحى الانتشار).
- **الحصول عليها:** هوائي مرسل في محرق عاكس **قطع مكافئ**؛ عندما تلاقي الأمواج **حاجزاً معدنياً ناقلاً مستوياً عمودياً** على منحى الانتشار تنعكس عنه فتتداخل مع الواردة.
- **الكشف:** `E⃗` بهوائي مستقبل **موازٍ** للمرسل؛ `B⃗` بحلقة نحاسية **عمودية على خطوط `B⃗`** — يتولد فيها توتر بالتحريض نتيجة تغير التدفق.
- **عند نقل الكاشفين:** تتوالى مستويات عقد (دلالة صغرى) وبطون (دلالة عظمى) متباعدة `λ/2`؛ **مستويات عقد `E` هي بطون `B` وبالعكس**؛ **الحاجز الناقل عقدة لـ`E` وبطن لـ`B`** (لأن الحقل الكهربائي المماسي ينعدم على سطح ناقل).

## ✍️ مثال محلول ١ — مسألة الوتر النموذجية [أستاذ طرق حل ١–٨]
وتر طوله `L = 1.2 m`، كتلته `m = 4.8 g`، مشدود بقوة `FT = 40 N`، يهتز بتواتر رنانة `f = 100 Hz` وسعتها `a = 2 mm`.
| | | |
|---|---|---|
| (١) `μ` | `μ = m/L = 4.8×10⁻³/1.2 = 4×10⁻³ kg·m⁻¹` | ٥+٣+١+١ |
| (٢) `v` | `v = √(FT/μ) = √(40/4×10⁻³) = √10⁴ = 100 m·s⁻¹` | ٥+٣+١+١ |
| (٣) `λ` | `λ = v/f = 100/100 = 1 m` | ٥+٣+١+١ |
| (٤) عدد المغازل | `n = L/(λ/2) = 1.2/0.5 = 2.4` — ليس صحيحاً ⇒ **لا تجاوب**؛ لتحقيقه بتغيير الشد: `n = 2 ⇒ λ = 1.2 m ⇒ v = 120 ⇒ FT = μv² = 4×10⁻³×14400 = 57.6 N` | ٥+٣+١+١ |
| (٥) بـ`FT = 57.6 N`: العقد والبطون | عقد عند `0, 0.6, 1.2 m`؛ بطون عند `0.3, 0.9 m` | ٣+٣ |
| (٦) سعة نقطة `x = 0.1 m` | `A = 2a·|sin(2πx/λ)| = 4×|sin(2π×0.1/1.2)| = 4×sin(π/6) = 2 mm` | ٥+٣+١+١ |
| (٧) المدروج الثالث | `f3 = 3·v/(2L) = 3×120/2.4 = 150 Hz` | ٥+٣+١+١ |

## ✍️ مثال ٢ — أكمل: قوة شد مجهولة

- `λ = 2L/n = ▢ m` · `v = λf = ▢ m·s⁻¹` · `FT = μv² = ▢ N`.
- لنحصل على مغزلين بالتواتر نفسه: `λ′ = ▢ m ⇒ v′ = ▢ ⇒ FT′ = ▢ N` (أكبر أم أصغر؟).

2. «أعداد صحيحة من ربع» بدل «فردية من ربع».
3. `n` = عدد العقد بدل عدد المغازل.
4. `μ` بـg/m بدل kg/m (يفسد `v` بعامل √1000).
5. وحدات m، Hz، m·s⁻¹، N.
