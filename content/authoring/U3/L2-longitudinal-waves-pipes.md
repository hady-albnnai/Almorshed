# الوحدة ٣ · الدرس ٢: الأمواج المستقرة الطولية — النابض، الأعمدة الهوائية، المزمار

> **في ٢٠٢٦: مسألة ٤ = ٣٠ درجة (مزمار).** المصادر: الكتاب ص ١٨٢–١٩٧ · الأستاذ فداء «الأمواج» (س١٠–س١٧ + طرق حل العمود الهوائي والمزمار + الجدول المقارن + مسائل ١–١١، ٢٧–٢٨ ص ١٩٤–١٩٥ و٢٩–٣٥ ص ٢٧٩–٢٨٠). الرموز: `v` سرعة الصوت في الغاز (m·s⁻¹)، `L` طول العمود/المزمار، `λ`، `f`، `n` رتبة الصوت، `T` درجة الحرارة المطلقة (K)، `ρ` كثافة الغاز، `M` الكتلة المولية، `d` الكثافة النسبية للهواء.

## 🔑 قبل أن تبدأ
**تحتاج:** كل L1 (عقد/بطون، `λ/2`، `λ/4`، `L = nλ/2` أو `(2n−1)λ/4`)، الغاز المثالي (`ρ = PM/RT`) من الصف السابق لفهم `v ∝ √(T/M)`.

**سؤال توقّع:**
> (أ) أنبوب مفتوح الطرفين وآخر مغلق من طرف، **الطول نفسه** — أيهما يصدر صوتاً أخفض (تواتراً أصغر)؟ (ب) في يوم حار، هل يصدر المزمار نفسه صوتاً أعلى أم أخفض تواتراً؟ (ج) عند النهاية المغلقة الهواء لا يتحرك — فهل الضغط هناك ثابت؟

## 📖 الفكرة

### ١. الأمواج المستقرة الطولية في نابض [أستاذ س١٠–س١١ / الكتاب ص ١٨٤]
عندما تعمل الرنانة تنتشر أمواج طولية وفق استطالة النابض حتى نهايته الثابتة فتنعكس وتتداخل مع الواردة ⇒ أمواج مستقرة طولية: **حلقات ساكنة (عقد اهتزاز `N`)** وحلقات تهتز بسعات متفاوتة (**بطون اهتزاز `A`**).

**عقد الاهتزاز ↔ بطون الضغط (المفهوم الأهم في الدرس):**
- **عقدة الاهتزاز:** ساكنة، تصلها الواردة والمنعكسة على تعاكس دائم؛ الحلقات المجاورة على الجانبين تتحرك **بجهتين متعاكستين دوماً**: تتقارب نصف دور وتتباعد نصف الدور التالي ⇒ **تغير أعظمي في الضغط** ⇒ **بطن ضغط**.
- **بطن الاهتزاز:** سعة عظمى، توافق دائم؛ الحلقات المجاورة **تترافق في الاهتزاز** فالمسافات بينها ثابتة ⇒ **لا تغير في الضغط** ⇒ **عقدة ضغط**.
(جواب سؤال التوقّع ج: **لا** — عند النهاية المغلقة الضغط يتغير أكثر ما يمكن.)

### ٢. الأعمدة الهوائية [أستاذ / الكتاب ص ١٨٦–١٨٨]
- **مفتوح:** أنبوب أسطواني مفتوح الطرفين مملوء بهواء ساكن.
- **مغلق:** مفتوح من طرف ومغلق من الآخر.
**تجربة الرنين (ص ١٨٦):** أنبوب زجاجي في ماء؛ رنانة مهتزة فوق طرفه المفتوح؛ نرفع الأنبوب ببطء: **أول صوت شديد** عند طول `L1 = λ/4` (رنين أول)؛ نتابع الرفع: **ثانٍ** عند `L2 = 3λ/4`. ⇒ **`L2 − L1 = λ/2`** — المسافة بين صوتين شديدين متتاليين = `λ/2` (أدق من `L1` وحدها لأنها تلغي **تصحيح الطرف**). ثم `v = λ·f`.

### ٣. المزمار — التعريف والمنبع [أستاذ / الكتاب ص ١٨٩]
**المزمار:** أنبوب أسطواني أو موشوري، مقطعه ثابت وصغير بالنسبة لطوله، جدرانه خشبية أو معدنية **لكي لا تشارك في الاهتزاز**، يحوي غازاً (الهواء غالباً) **يهتز بالتجاوب مع المنبع الصوتي**.
**تصنيف المنابع:**
| المنبع | ما يتشكل عنده |
|---|---|
| **ذو فم** (نفخ على حافة) | **بطن اهتزاز `A`** (عقدة ضغط) |
| **ذو لسان** (ريشة تهتز) | **عقدة اهتزاز `N`** (بطن ضغط) |
**النهايات:** **مغلقة ⇒ عقدة اهتزاز `N`** (بطن ضغط) · **مفتوحة ⇒ بطن اهتزاز `A`** (عقدة ضغط).

**تعليل الأمواج المستقرة في المزمار [أستاذ س١٢]:** تهتز طبقة الهواء المجاورة للمنبع فينتشر الاهتزاز طولياً في هواء المزمار وينعكس عند نهايته؛ تتداخل الواردة والمنعكسة ⇒ أمواج مستقرة طولية.
**لماذا ينعكس عند النهاية المفتوحة؟ [أستاذ س١٣]:** الانضغاط الوارد يزيح طبقة الهواء الأخيرة إلى الخارج فيسبب **تخلخلاً وراءها**، فيتهافت هواء المزمار لملء هذا الفراغ ⇒ ينتشر **تخلخل** من النهاية إلى البداية — هو **منعكس الانضغاط** الوارد (انعكاس بتعاكس في الضغط، بتوافق في الاهتزاز).

### ٤. متشابه الطرفين / مختلف الطرفين [أستاذ س١٤]
| | المنبع | النهاية | النوع |
|---|---|---|---|
| فم `A` | + | مفتوحة `A` | **متشابه** |
| لسان `N` | + | مغلقة `N` | **متشابه** |
| فم `A` | + | مغلقة `N` | **مختلف** |
| لسان `N` | + | مفتوحة `A` | **مختلف** |

> **⚠️ الخطأ الشائع ١:** «مغلق = مختلف الطرفين دائماً». لا — مزمار ذو **لسان** نهايته **مغلقة** متشابه الطرفين (`N…N`). النوع يتحدد بـ**تشابه** الطرفين اهتزازياً، لا بالفتح والإغلاق.

## 🧮 البرهان المُرقَّم ١ — تواتر المزمار متشابه الطرفين [أستاذ س١٥ / الكتاب ص ١٩٠]
| # | | درجة |
|---|---|---|
| ① | الطرفان متشابهان (`A…A` أو `N…N`) ⇒ بينهما عدد صحيح من المغازل ⇒ `L = n·λ/2` | ٤ |
| ② | `λ = v/f` ⇒ `L = n·v/(2f)` | ٣ |
| ③ | **`f = n·v/(2L)`**، `n = 1, 2, 3, …` رتبة الصوت (المدروجات) | ٤ |
| ④ | الأساسي `f1 = v/2L`؛ يصدر **كل المدروجات** `2f1, 3f1, …` | ٣ |
**لإصدار المدروجات:** نزيد نفخ الهواء تدريجياً؛ أو نغير طول اللسان في ذي اللسان.

## 🧮 البرهان المُرقَّم ٢ — مختلف الطرفين (**مسألة ٤ ٢٠٢٦**) [أستاذ س١٦ / الكتاب ص ١٩٠–١٩١]
| # | | درجة |
|---|---|---|
| ① | طرف `A` وطرف `N` ⇒ عدد فردي من أرباع الموجة: `L = (2n−1)·λ/4` | ٤ |
| ② | `λ = v/f` | ٣ |
| ③ | **`f = (2n−1)·v/(4L)`**، `n = 1, 2, …` | ٤ |
| ④ | الأساسي `f1 = v/4L`؛ يصدر **المدروجات الفردية فقط** `3f1, 5f1, …` — كل نصف مغزل مدروج | ٣ |

**جواب سؤال التوقّع (أ):** المغلق (مختلف) `f1 = v/4L` = **نصف** تواتر المفتوح `v/2L` ⇒ **أخفض** بأوكتاف. **[أستاذ الجدول]** لطول أقصر يعطي التواتر نفسه: المختلف أقصر بالنصف.

### ٥. سرعة الصوت في غاز المزمار [أستاذ س١٧ / الكتاب ص ١٩١]
تتوقف على:
1. **درجة حرارة الغاز:** `v ∝ √T` (المطلقة بالكلفن) ⇒ **`v2/v1 = √(T2/T1)`**.
2. **نوع الغاز:** `v ∝ 1/√ρ` — وبالكتلة المولية `v ∝ 1/√M`؛ بالكثافة النسبية للهواء `d`: **`v = v_air/√d`**.
(جواب سؤال التوقّع ب: يوم حار ⇒ `v↑` ⇒ `f = nv/2L ↑` ⇒ **أعلى**.)
**[أستاذ ٣٤ ص ٢٨٠]** إذا كان هواء الأنبوب أدفأ من الغرفة ⇒ سرعة الصوت في الغرفة **أقل**.

### ٦. المواقتة [أستاذ طرق الحل]
مزماران **مواقتان** = يصدران **التواتر نفسه**. إذا تغيرت الحرارة أو الغاز، يُحفظ التواتر بتغيير الطول: `f = nv/2L` ثابت ⇒ `L2/L1 = v2/v1 = √(T2/T1)` (أو `1/√d`).

### ٧. الجدول المقارن الجامع [أستاذ]
| | وتر مقيد / عمود مفتوح / **مزمار متشابه** | وتر طليق / عمود مغلق / **مزمار مختلف** |
|---|---|---|
| الطول | `L = nλ/2` | `L = (2n−1)λ/4` |
| التواتر | `f = nv/2L` | `f = (2n−1)v/4L` |
| الأساسي | `v/2L` | `v/4L` (نصف) |
| أقصر طول لتواتر معين | `λ/2` | `λ/4` |
| `n` | عدد المغازل = عدد المدروجات | `2n−1` رتبة؛ عدد العقد = عدد البطون = `n` |
| المدروجات | **كلها** (كل مغزل مدروج) | **الفردية فقط** (كل نصف مغزل مدروج) |
| **المدروج التالي للأساسي** | `2f1` | **`3f1`** |

> **⚠️ الخطأ الشائع ٢:** في المختلف «المدروج الثاني = `2f1`». المدروج **التالي** هو `3f1` (لأن `2f1` يتطلب `L = λ/2` — بطنان أو عقدتان عند الطرفين، مستحيل مع طرفين مختلفين). في مسألة ٢٠٢٦ هذا البند حاسم.

## ✍️ مثال محلول ١ — بنية مسألة ٢٠٢٦ الرابعة (٣٠ درجة) [أستاذ طرق الحل]
مزمار ذو فم نهايته مغلقة، طوله `L = 0.5 m`؛ سرعة الصوت في هوائه `v = 340 m·s⁻¹`.
| | | |
|---|---|---|
| (١) النوع | منبع ذو فم `A` + نهاية مغلقة `N` ⇒ **مختلف الطرفين** | ٣ |
| (٢) الأساسي | `L = λ/4 ⇒ λ = 2 m` ⇒ `f1 = v/4L = 340/2 = 170 Hz` | ٥+٣+١+١ |
| (٣) المدروج التالي | `f3 = 3f1 = 510 Hz` (الفردية فقط) | ٥+٣+١ |
| (٤) توزع العقد والبطون عند `f3` | `L = 3λ/4`، `λ = 2/3 m`؛ بطن عند الفم (`x = 0`)، عقدة عند `λ/4 = 1/6 m`، بطن عند `1/3`، عقدة عند النهاية `0.5 m` — رسم | ٥ |
| (٥) طول مزمار متشابه الطرفين مواقت له (يصدر `170 Hz` أساسياً) | `f1 = v/2L′ ⇒ L′ = 340/340 = 1 m` (ضعف الطول) | ٥+٣+١+١ |
| (٦) الحرارة ترتفع من `17 °C` (`290 K`) إلى `47 °C` (`320 K`): `v′` والتواتر الجديد | `v′ = 340×√(320/290) ≈ 357 m·s⁻¹` ⇒ `f1′ = 357/2 ≈ 178.6 Hz` | ٥+٣+١+١ |

## ✍️ مثال محلول ٢ — تجربة الرنين (الكتاب ص ١٨٨)
أنبوب في ماء ورنانة `f = 500 Hz`؛ صوت شديد أول عند `L1 = 16.5 cm` وثانٍ عند `L2 = 50.5 cm`.
| | | |
|---|---|---|
| `λ` | `L2 − L1 = λ/2 = 34 cm ⇒ λ = 0.68 m` | ٥+٣+١+١ |
| `v` | `v = λf = 0.68×500 = 340 m·s⁻¹` | ٥+٣+١+١ |
| لماذا لا نستخدم `L1 = λ/4` وحدها؟ | لأن البطن الحقيقي خارج فوهة الأنبوب قليلاً (تصحيح الطرف)؛ الفرق `L2 − L1` يلغيه | ٣ |
| الرنين الثالث | `L3 = 5λ/4 = 85 cm` | ٣+١ |

## ✍️ مثال ٣ — أكمل: تغيير الغاز
مزمار متشابه الطرفين `L = 0.4 m` يصدر أساسياً `f1 = 425 Hz` بالهواء (`v = 340`). نملؤه بغاز كثافته النسبية للهواء `d = 0.25`.
- `v′ = v/√d = ▢ m·s⁻¹` · `f1′ = v′/2L = ▢ Hz`.
- ليبقى مواقتاً للأصلي: `L′ = v′/(2×425) = ▢ m`.
<details><summary>الحل</summary>v′ = 680 m/s · f1′ = 850 Hz · L′ = 0.8 m</details>

## ⚖️ خصومات السلم
1. النوع خطأ (فم+مغلقة = مختلف) ⇒ العلاقة كلها خطأ.
2. `T` بالسلسيوس في `√(T2/T1)`.
3. «المدروج الثاني `2f1`» في المختلف.
4. رسم توزع العقد/البطون بلا تحديد الطرفين.
5. وحدات m·s⁻¹، Hz، m.
