# نوطة الأستاذ فداء البنّي — الوحدة الأولى: الحركة والتحريك
### النسخة المصحَّحة على الكتاب الوزاري (رموزاً وفهرساً) — بقالب «الخطوة ⇐ الصياغة» وتنبيهات السلم

> **المصدر:** ملخصات الأستاذ فداء (النواسات · السوائل · النسبية) + الكتاب الرسمي (طبعة ٢٠٢٤–٢٠٢٥) + سلم ٢٠٢٦.
> **الفهرس = فهرس الكتاب حرفياً:** الوحدة الأولى فيها **خمسة فصول**: النواس المرن (ص ٦) · نواس الفتل (ص ٢١) · النواس الثقلي (ص ٢٩) · **السوائل (ص ٤٣)** · **النسبية الخاصة (ص ٥٥)**. لا «وحدة سوائل» ولا «وحدة نسبية» مستقلتين.
> **الرموز حرفياً كالكتاب:** `XmaX` `ω0` `T0` `x0` `Fs0` `φ` `IΔ` `θmax` · ثابت النابض `k` · ثابت الفتل **`C`** (ورد `k` في بعض الطبعات — الاعتماد النهائي للأستاذ) · `Qv` `Qm` `ρ` · `γ` `m0` `E0`.
> `g = 10 m·s⁻²` و `π² = 10` كما في المسائل الوزارية.
> **حالة الاعتماد:** بانتظار الأستاذ فداء. كل ما وُسم **[أستاذ]** من ملخصاته؛ **[سلم]** من سلم ٢٠٢٦؛ **[كتاب ص]** من الكتاب.

## الفصل الأول — النواس المرن غير المتخامد (الحركة التوافقية البسيطة) · الكتاب ص ٦–٢٠

### التعريف الامتحاني [أستاذ]
النواس المرن غير المتخامد: نابض مرن **مهمل الكتلة**، حلقاته متباعدة، ثابت صلابته `k`، معلّق فيه جسم صلب كتلته `m`، يمكنه أن يهتز إلى جانبي نقطة ثابتة تدعى **مركز الاهتزاز** (موضع التوازن)، دون تخامد (لا احتكاك).

### 🧪 تجربة: قياس ثابت الصلابة ودراسة الدور [كتاب ص ٨–١٢]
| البند | المضمون |
|---|---|
| الأدوات | حامل شاقولي · نابض مرن · مسطرة مدرّجة · كتل عيارية · ميقاتية |
| الخطوات | ١) نعلّق `m` فيستطيل النابض `x0` (الاستطالة السكونية). ٢) نسحب الجسم نحو الأسفل مسافة `XmaX` ونتركه بلا سرعة ابتدائية عند `t = 0`. ٣) نقيس زمن **١٠ هزات** ونقسم على ١٠ ⇒ `T0`. ٤) نكرّر بتغيير `m` ثم بتغيير `XmaX`. |
| المشاهدة | `T0` **لا يتغير** بتغيّر `XmaX` · يزداد بزيادة `m` · ينقص بزيادة `k` |
| الاستنتاج | عند التوازن `m·g = k·x0` ⇒ `k = m·g / x0` · و `T0 = 2π√(m/k) = 2π√(x0/g)` |

### ◄ استنتاج ١: محصلة القوى قوة إرجاع `F = −k·x` [أستاذ س١ · كتاب ص ١٠–١١]
| الخطوة الفيزيائية | الصياغة |
|---|---|
| الجملة المدروسة: الجسم `m` · القوى الخارجية: الثقل `w⃗`، قوة توتر النابض `F⃗s` | — |
| **حالة السكون** — شرط التوازن | `w⃗ + F⃗s0 = 0⃗` |
| الإسقاط على محور `x′x` شاقولي موجّه نحو الأسفل | `w − Fs0 = 0` ⇒ `w = Fs0 = k·x0` … (١) |
| **حالة الحركة** — القانون الثاني لنيوتن | `w⃗ + F⃗s = m·a⃗` |
| الإسقاط على المحور نفسه، مع `Fs = k·(x0 + x)` | `w − k·(x0 + x) = m·a` |
| التعويض من (١) وفكّ القوس | `k·x0 − k·x0 − k·x = m·a` |
| النتيجة | **`F = −k·x = m·a`** — قوة إرجاع (إشارتها تعاكس إشارة `x` دائماً) |

> ⚠️ **تنبيه السلم:** ذكر الجملة والقوى **قبل** المعادلة، وتحديد المحور وجهته، وكتابة العلاقة الشعاعية بأسهم **ثم** الإسقاط — كل واحدة سطر بدرجة.

### ◄ استنتاج ٢: الحركة جيبية والدور الخاص [سلم ٢٠٢٦ س٣-١ — ٢٥ درجة]
| الخطوة | الصياغة | الدرجة [سلم] |
|---|---|---|
| من `F = m·a` و `a = x″` | `m·x″ = −k·x` ⇒ **`x″ + (k/m)·x = 0`** | — (تُعطى في السؤال) |
| معادلة تفاضلية من المرتبة الثانية تقبل حلاً جيبياً | `x = XmaX·cos(ω0·t + φ)` | ٥ — **إهمال `φ` يخسر ١** |
| نشتق مرتين | `x′ = −ω0·XmaX·sin(ω0·t + φ)` | ٤ |
| | `x″ = −ω0²·XmaX·cos(ω0·t + φ)` | ٤ |
| أي | `x″ = −ω0²·x` | ٢ — **إهمال الإشارة السالبة يخسر ٤** |
| بالمطابقة | `ω0² = k/m` ⇒ `ω0 = √(k/m) > 0` (ما تحت الجذر موجب) | ٢ + (١+١) |
| لكن `ω0 = 2π/T0` | `2π/T0 = √(k/m)` | ٢ |
| النتيجة | **`T0 = 2π·√(m/k)`** | ٤ |

> 💡 **[أستاذ]** البرهان نفسه بالبنية نفسها يُطلب لنواس الفتل (`θ`, `C/IΔ`) وللدارة المهتزة (`q`, `1/LC`) — برهان واحد يُحفظ ثلاث مرات.

### ⚡ القوانين
| المقدار | العلاقة | ملاحظة |
|---|---|---|
| المطال | `x = XmaX·cos(ω0·t + φ)` | ثوابت الحركة: `XmaX, ω0, φ` |
| السرعة | `v = x′ = −ω0·XmaX·sin(ω0·t + φ)` | `vmax = ω0·XmaX` في مركز الاهتزاز |
| التسارع | `a = x″ = −ω0²·x` | `amax = ω0²·XmaX` في الطرفين |
| العلاقة اللازمنية | `v² = ω0²·(XmaX² − x²)` | السرعة في أي مطال دون زمن |
| الطاقة | `E = ½·k·x² + ½·m·v² = ½·k·XmaX² = const` | كامنة فقط في الطرفين، حركية فقط في المركز |
| الدور | `T0 = 2π√(m/k) = 2π√(x0/g)` | لا يتعلق بـ`XmaX` ولا بـ`g` (الصيغة الأولى) |

### 📌 شروط البدء وتعيين `φ` [أستاذ — «نناقش في تابع السرعة»]
نعوّض `t = 0` في تابع المطال فنحصل على `cos φ`، وقد يعطي قيمتين — **نحسم بالسرعة**: `v(0) = −ω0·XmaX·sin φ`.

| الحالة عند `t = 0` | `cos φ` | إشارة `sin φ` من السرعة | `φ` |
|---|---|---|---|
| تُرك من المطال الأعظمي الموجب | `+1` | — | `0` |
| تُرك من المطال الأعظمي السالب | `−1` | — | `π` |
| مرّ بمركز الاهتزاز بالاتجاه **الموجب** (`v > 0`) | `0` | `sin φ < 0` | **`3π/2`** (وتُقبل `−π/2` إن كُتب المجال) |
| مرّ بمركز الاهتزاز بالاتجاه **السالب** (`v < 0`) | `0` | `sin φ > 0` | **`π/2`** |
| `x(0) = +XmaX/2` والحركة بالاتجاه السالب | `½` | `sin φ > 0` | `π/3` |

> ⚠️ **تنبيه السلم:** الكتاب يأخذ `φ` في `[0, 2π[`. الخطأ الشائع: كتابة `φ = −π/2` للمرور الموجب بلا ذكر المجال — يُحاسب كخطأ طور (**−١**).

### 🎯 مسائل النسبة [أستاذ — نمط س١ الاختياري]
`T0′/T0 = √(m′/m)·√(k/k′)` ⇒ مضاعفة `XmaX` ⇒ `T0′ = T0` · `k′ = k/4` ⇒ `T0′ = 2T0` · `m′ = m/4` ⇒ `T0′ = T0/2` · (`m′ = m/2`, `k′ = 2k`) ⇒ `ω0′ = 2ω0`.

### ✍️ مسألة نموذجية بالسلم [كتاب ص ١٩ م٣ · أستاذ طرق الحل ص ٤]
جسم `m = 1 kg` معلّق بنابض شاقولي، ينجز ١٠ هزات في `10 s`، ويرسم قطعة مستقيمة طولها `16 cm`. (`g = 10`, `π² = 10`)

| الطلب | القانون العام ⇐ التعويض ⇐ الناتج | الدرجات |
|---|---|---|
| قراءة المعطيات المخفية | `T0 = 10/10 = 1 s` · `2·XmaX = 16 cm ⇒ XmaX = 0.08 m` | — |
| (١) الاستطالة السكونية | `m·g = k·x0` و `T0 = 2π√(m/k) ⇒ k = 4π²m/T0² = 40 N·m⁻¹` ⇒ `x0 = m·g/k = 10/40 = 0.25 m` | ٥+٥+٣+(١+١) |
| (٢) السرعة العظمى | `vmax = ω0·XmaX = (2π/T0)·XmaX = 2π×0.08 ≈ 0.5 m·s⁻¹` | ٥+٣+(١+١) |
| (٣) التسارع في `x = 6 cm` | `a = −ω0²·x = −4π²×0.06 = −2.4 m·s⁻²` (نحو المركز) | ٥+٣+(١+١) |
| (٤) الطاقة في `x = −4 cm` | `Ep = ½k·x² = ½×40×0.04² = 0.032 J` · `Ek = ½k(XmaX² − x²) = 0.096 J` | ٥+٣+(١+١) ×٢ |

> ⚠️ **تنبيه السلم:** «١٠ هزات في ١٠ ثوانٍ» و«قطعة طولها ١٦ cm» معطيات مخفية — مَن يأخذ `XmaX = 16 cm` يخسر الطلب كله.

## الفصل الثاني — الاهتزازات الجيبية الدورانية: نواس الفتل غير المتخامد · الكتاب ص ٢١–٢٨

### التعريف الامتحاني [أستاذ]
سلك معدني شاقولي مهمل الكتلة ثابت فتله `C`، مثبَّت من طرفه العلوي، تُعلَّق من منتصف طرفه السفلي ساق أفقية متجانسة عزم عطالتها بالنسبة لمحور السلك `IΔ`. إذا أُديرت الساق بزاوية `θmax` وتُركت اهتزّت حول المحور دون تخامد.

### 🧪 التجارب الثلاث [أستاذ — «التجارب الثلاث» · كتاب ص ٢٣–٢٥]
| التجربة | نغيّر | نثبّت | المشاهدة | الاستنتاج |
|---|---|---|---|---|
| ١ | السعة الزاوية `θmax` | `IΔ`, السلك | `T0` ثابت | الاهتزاز **متواقت** — الدور لا يتعلق بالسعة |
| ٢ | `IΔ` (نُبعد كتلتين متماثلتين عن المحور) | السلك | `T0` يزداد | `T0 ∝ √IΔ` |
| ٣ | السلك (طوله `l`، قطره `d`، مادته) | `IΔ` | `T0` يزداد بطول السلك وينقص بغلظه | `C = ثابت·d⁴/l` ⇒ `T0 ∝ 1/√C` |

> **[أستاذ + كتاب ص ٢٥]** ثابت الفتل يتعلق بالسلك فقط: يتناسب طرداً مع **القوة الرابعة لقطره** وعكساً مع طوله. ⇒ ربع الطول ⇒ `C` ٤ أمثال ⇒ **`T0′ = T0/2`** (سؤال ٢٠٢٦ س١).

### ◄ استنتاج: المعادلة التفاضلية والدور الخاص
| الخطوة الفيزيائية | الصياغة |
|---|---|
| الجملة: الساق · القوى: الثقل `w⃗`، رد فعل السلك `R⃗`، مزدوجة الفتل | — |
| العلاقة الأساسية في التحريك الدوراني | `ΣΓ = IΔ·θ″` |
| عزما `w⃗` و`R⃗` معدومان (حاملاهما يلاقيان المحور) | `Γw = 0`, `ΓR = 0` |
| عزم مزدوجة الفتل إرجاعي | **`Γ = −C·θ`** |
| التعويض | `−C·θ = IΔ·θ″` ⇒ **`θ″ + (C/IΔ)·θ = 0`** |
| حل جيبي مع `ω0² = C/IΔ > 0` | `θ = θmax·cos(ω0·t + φ)` — **جيبية دورانية** |
| الدور | **`T0 = 2π·√(IΔ/C)`** |

> ⚠️ **تنبيه السلم:** تعليل انعدام عزمَي الثقل ورد الفعل («حاملهما يمر من المحور») سطر بدرجة — لا يُحذف.

### ⚡ القوانين
| المقدار | العلاقة | الوحدة |
|---|---|---|
| عزم المزدوجة | `Γ = −C·θ` | `N·m` |
| ثابت الفتل | `C` (خاصية السلك: `∝ d⁴/l`) | `N·m·rad⁻¹` |
| الدور الخاص | `T0 = 2π√(IΔ/C)` | `s` |
| السرعة الزاوية العظمى | `θ′max = ω0·θmax` | `rad·s⁻¹` |
| الطاقة | `E = ½·C·θ² + ½·IΔ·θ′² = ½·C·θmax²` | `J` |
| عزوم عطالة | ساق حول منتصفها `(1/12)·M·L²` · كتلة نقطية `m·r²` · قرص `½·m·r²` · هايغنز `IΔ = IG + m·a²` | `kg·m²` |

> **ملاحظة الرمز:** الكتاب (ص ٢٥) يكتب ثابت الفتل `C` في العلاقة `C = ثابت·d⁴/l`؛ ورقة ٢٠٢٦ تستخدم `C`. حيثما ظهر `k` للفتل في طبعة قديمة يُقرأ `C` — **بانتظار حسم الأستاذ**.

## الفصل الثالث — الاهتزازات غير التوافقية: النواس الثقلي (المركّب والبسيط) · الكتاب ص ٢٩–٤٢

### التعريفان [أستاذ]
- **المركّب:** كل جسم صلب يمكنه الاهتزاز حول محور أفقي ثابت `Δ` **لا يمر** من مركز عطالته `G`، ويبعد عنه مسافة `d`.
- **البسيط:** كرة صغيرة كتلتها `m` معلّقة بخيط مهمل الكتلة غير قابل للامتداد طوله `l` — حالة خاصة من المركّب بـ`IΔ = m·l²`, `d = l`.

### ◄ استنتاج: معادلة المركّب ودوره في السعات الصغيرة [أستاذ س١ · كتاب ص ٣١–٣٢]
| الخطوة الفيزيائية | الصياغة |
|---|---|
| الجملة: الجسم الصلب · القوى: الثقل `w⃗`، رد فعل المحور `R⃗` | — |
| العلاقة الأساسية في التحريك الدوراني | `ΣΓ = IΔ·θ″` ⇒ `Γw + ΓR = IΔ·θ″` |
| عزم `R⃗` معدوم لأن حامله يلاقي المحور | `ΓR = 0` |
| عزم الثقل (ذراعه `d·sin θ`، مُرجِع) | `Γw = −m·g·d·sin θ` |
| المعادلة العامة | **`θ″ + (m·g·d/IΔ)·sin θ = 0`** — **غير توافقية** (لوجود `sin θ`) |
| في السعات الصغيرة | `sin θ ≈ θ` (بالراديان) |
| المعادلة تصبح | `θ″ + (m·g·d/IΔ)·θ = 0` ⇒ `ω0² = m·g·d/IΔ` |
| الدور الخاص | **`T0 = 2π·√(IΔ/(m·g·d))`** |
| البسيط: `IΔ = m·l²`, `d = l` | **`T0 = 2π·√(l/g)`** |

> ⚠️ **تنبيه السلم:** كلمة «غير توافقية» **ثم** «تصبح جيبية دورانية في السعات الصغيرة» — كلتاهما تُكتبان. وإسقاط `ΓR = 0` بلا تعليل يخسر درجته.

### 📌 ماذا يعتمد عليه الدور؟ [أستاذ]
- **لا يتعلق بالكتلة** (تظهر `m` لكن `IΔ ∝ m` فتُختصر) ولا بالسعة (الصغيرة).
- يتعلق بـ`g` ⇒ **الميقاتية ذات النواس تتأخر بالارتفاع** وعلى القمر (`g` أصغر ⇒ `T0` أطول) — تعليل وزاري متكرر.
- **النواس البسيط المواقت** للمركّب: نفس الدور ⇒ **`l = IΔ/(m·d)`**.

### ⚡ الطاقة والتوتر في النواس البسيط [كتاب ص ٣٦]
| المقدار | العلاقة |
|---|---|
| نظرية الطاقة الحركية بين `θmax` و`θ` | `½·m·v² − 0 = m·g·l·(cos θ − cos θmax)` (عمل `T⃗` معدوم لأنه عمودي على المسار) |
| السرعة في أي زاوية | `v² = 2·g·l·(cos θ − cos θmax)` |
| توتر الخيط | **`T = m·g·(3cos θ − 2cos θmax)`** — أعظمي في الشاقول، أصغري في الطرفين |

### ✍️ مسألة نموذجية بالسلم — **مسألة ٢٠٢٦ الأولى (٨٥ درجة)** [سلم]
ساق مهملة الكتلة طولها `L = 80 cm` تحمل في طرفيها كتلتين نقطيتين `m1`؛ محور أفقي `Δ` يبعد `L/4` عن إحداهما. (`g = 10`, `π² = 10`)

| الطلب | القانون العام ⇐ التعويض ⇐ الناتج | الدرجات |
|---|---|---|
| (١) عزم العطالة | `IΔ = m1·(L/4)² + m1·(3L/4)² = (10/16)·m1·L² = (5/8)·m1·L²` | ٥+٣+١ |
| (٢) بعد مركز العطالة | `d = (3L/4 − L/4)/2 = L/4` (منتصف الساق يبعد `L/4` عن المحور) | ٣+١ |
| (٣) الدور الخاص | `T0 = 2π√(IΔ/(2m1·g·d)) = 2π√((5/8)L²/(2g·L/4)) = π√(5L/g) = π√0.4 = √(10×0.4) = 2 s` | ٥+٣+١+١ |
| (٤) المواقت | `l = IΔ/(M·d) = (5/8)L²/(2·L/4) = (5/4)·L = 1 m` | ٥+٣+١+١ |

> ⚠️ **تنبيه السلم:** الكتلة `m1` تُختصر ولا تظهر في الناتج — إبقاؤها في النتيجة يُحاسب. و`π² = 10` يُستخدم فقط عند التعويض العددي، لا في العلاقة.

## الفصل الرابع — ميكانيك السوائل المتحركة · الكتاب ص ٤٣–٥٤

### المفاهيم [أستاذ «مفاهيم أساسية» · كتاب ص ٤٤–٤٥]
- **جسيم السائل:** جزء صغير جداً بالنسبة لأبعاد السائل، كبير جداً بالنسبة للجزيئات.
- **خط الانسياب:** المسار الذي يسلكه جسيم السائل؛ شعاع السرعة يمسّه في كل نقطة. **لا يتقاطع خطّا انسياب** (وإلا كان لجسيم واحد سرعتان في نقطة واحدة).
- **السائل المثالي (٤ صفات — سؤال نظري متكرر):** غير قابل للانضغاط (`ρ` ثابتة) · عديم اللزوجة · جريانه مستقر (السرعة في نقطة ما لا تتغير بالزمن) · جريانه غير دوراني.

### ⚡ القوانين
| المقدار | العلاقة | الوحدة |
|---|---|---|
| المنسوب الحجمي | `Qv = ΔV/Δt = s·v` | `m³·s⁻¹` |
| المنسوب الكتلي | `Qm = Δm/Δt = ρ·s·v` | `kg·s⁻¹` |
| معادلة الاستمرار | **`s1·v1 = s2·v2`** — السرعة تتناسب عكساً مع مساحة المقطع | — |
| معادلة برنولي | **`P + ½·ρ·v² + ρ·g·z = const`** | `Pa` (كل حدّ = طاقة لواحدة الحجوم) |
| أنبوب أفقي | `P1 + ½ρv1² = P2 + ½ρv2²` ⇒ حيث تزداد السرعة ينقص الضغط | |
| تورشيللي | **`v = √(2·g·h)`** (سرعة خروج السائل من ثقب على عمق `h`) | `m·s⁻¹` |

### ◄ استنتاج معادلة برنولي [أستاذ س٣ · كتاب ص ٤٧–٤٩] — بنظرية الطاقة الحركية
| الخطوة الفيزيائية | الصياغة |
|---|---|
| الجملة: كتلة `Δm` من السائل تنتقل من المقطع ١ إلى ٢ خلال `Δt` (حجمها `ΔV` نفسه — غير قابل للانضغاط) | `Δm = ρ·ΔV` |
| القوى العاملة: قوة ضغط الدخول `F1 = P1·s1` (محرّكة) · قوة ضغط الخروج `F2 = P2·s2` (مقاومة) · الثقل | — |
| عمل قوى الضغط | `W1 = +P1·s1·Δx1 = +P1·ΔV` · `W2 = −P2·s2·Δx2 = −P2·ΔV` |
| عمل الثقل عند الارتفاع من `z1` إلى `z2` | `Ww = −Δm·g·(z2 − z1)` |
| نظرية الطاقة الحركية `ΔEk = ΣW` | `½Δm·v2² − ½Δm·v1² = (P1 − P2)·ΔV − Δm·g·(z2 − z1)` |
| نقسم على `ΔV` ونستخدم `ρ = Δm/ΔV` | `½ρv2² − ½ρv1² = P1 − P2 − ρg(z2 − z1)` |
| نجمع حدود كل مقطع على حدة | **`P1 + ½ρv1² + ρgz1 = P2 + ½ρv2² + ρgz2`** |

> ⚠️ **تنبيه السلم:** إشارة عمل قوة الخروج **سالبة** (مقاومة) وعمل الثقل سالب عند الصعود — إشارتان بدرجتين.

### 🧪 تجربة: أنبوب فنتوري [كتاب ص ٥٠]
أنبوب أفقي بمقطعين `s1 > s2` يحمل مانومترين شاقوليين. عند الجريان: **ارتفاع السائل في مانومتر المقطع الضيق أقل** ⇒ `P2 < P1` بينما `v2 > v1` — تحقق تجريبي لبرنولي في الأنبوب الأفقي. فرق الضغط: `P1 − P2 = ρ·g·Δh`.

### ✍️ مسألة نموذجية [كتاب ص ٥٣ نمط]
ماء (`ρ = 1000`) في أنبوب أفقي: `s1 = 40 cm²`, `P1 = 1.5×10⁵ Pa`, `v1 = 2 m·s⁻¹`, `s2 = 10 cm²`.

| الطلب | الحل | الدرجات |
|---|---|---|
| (١) المنسوبان | `Qv = s1·v1 = 40×10⁻⁴×2 = 8×10⁻³ m³·s⁻¹` · `Qm = ρ·Qv = 8 kg·s⁻¹` | ٥+٣+(١+١) |
| (٢) `v2` | `s1v1 = s2v2 ⇒ v2 = (40/10)×2 = 8 m·s⁻¹` | ٥+٣+(١+١) |
| (٣) `P2` | `P2 = P1 + ½ρ(v1² − v2²) = 1.5×10⁵ + 500×(4 − 64) = 1.2×10⁵ Pa` | ٥+٣+(١+١) |

> ⚠️ **تنبيه السلم:** التحويل `cm² → m²` بالضرب في `10⁻⁴` سطر بدرجة، والوحدة `Pa` (أو `N·m⁻²`) إلزامية.

## الفصل الخامس — النسبية الخاصة · الكتاب ص ٥٥–٦٧

### الفرضيتان [أستاذ · كتاب ص ٥٦]
1. **مبدأ النسبية:** قوانين الفيزياء واحدة في جميع جمل المقارنة العطالية.
2. **ثبات سرعة الضوء:** سرعة الضوء في الخلاء `c = 3×10⁸ m·s⁻¹` واحدة لجميع المراقبين العطاليين مهما كانت حركة المنبع أو المراقب.

> **[كتاب ص ٥٥]** الدافع التاريخي: فشل رصد «رياح الأثير» (تجربة مايكلسون ومورلي: **لا انزياح** في أهداب التداخل) ⇒ لا وجود للأثير.

### ⚡ القوانين [كتاب ص ٥٧–٦٤]
| المقدار | العلاقة | ملاحظة |
|---|---|---|
| عامل لورنتز | **`γ = 1/√(1 − v²/c²)`** `≥ 1` | عدد مجرد |
| تمدد الزمن | **`t = γ·t0`** | `t0` الزمن الخاص (في جملة سكون الحدث) — الساعة المتحركة أبطأ |
| تقلص الطول | **`L = L0/γ`** | `L0` الطول الخاص؛ التقلص في اتجاه الحركة فقط |
| كمية الحركة | `p = γ·m0·v` | |
| طاقة السكون | **`E0 = m0·c²`** | |
| الطاقة الكلية | **`E = γ·m0·c²`** | |
| الطاقة الحركية | **`Ek = E − E0 = (γ − 1)·m0·c²`** | تؤول إلى `½m0v²` عندما `v ≪ c` |

> **ملاحظة رموز:** الكتاب الحالي يكتب الطاقة بدلالة `m0` و`γ` ولا يستخدم «الكتلة النسبية» كمقدار مستقل. إن وردت في نوطة قديمة `m = γ·m0` فهي مكافئة، لكن **الصياغة الامتحانية بـ`γ·m0`**.

### ◄ إثبات أيلولة `Ek` إلى الصيغة الكلاسيكية عندما `v ≪ c` [أستاذ س٣-٤]
| الخطوة | الصياغة |
|---|---|
| عامل لورنتز بأس كسري | `γ = (1 − v²/c²)^(−½)` |
| تقريب `(1 − ε)^(−½) ≈ 1 + ½ε` لـ`ε = v²/c² ≪ 1` | `γ ≈ 1 + ½·v²/c²` |
| التعويض | `Ek = (γ − 1)·m0·c² ≈ ½·(v²/c²)·m0·c²` |
| النتيجة | **`Ek ≈ ½·m0·v²`** |

### 🧪 التحقق التجريبي [كتاب ص ٦٠]
الساعات الذرية المحمولة جواً تأخرت عن الأرضية بمقدار يوافق `t = γ·t0` — و«مفارقة التوأمين» تفسيرٌ لا مفارقة: التوأم المسافر ليس في جملة عطالية طوال الرحلة.

### ✍️ مسألة نموذجية [أستاذ تطبيق ص ٦١]
إلكترون `m0 = 9×10⁻³¹ kg` بسرعة `v = 0.8c`.

| الطلب | الحل | الدرجات |
|---|---|---|
| (١) `γ` | `γ = 1/√(1 − 0.64) = 1/0.6 = 5/3` | ٥+٣+١ |
| (٢) `E0` | `E0 = m0c² = 9×10⁻³¹×9×10¹⁶ = 8.1×10⁻¹⁴ J` | ٥+٣+(١+١) |
| (٣) `E` و`Ek` | `E = γE0 = 1.35×10⁻¹³ J` · `Ek = E − E0 = 5.4×10⁻¹⁴ J` | ٥+٣+(١+١) ×٢ |
| (٤) بالـ`MeV` | `E0 = 8.1×10⁻¹⁴/1.6×10⁻¹³ ≈ 0.51 MeV` | ٣+١ |

> ⚠️ **تنبيه السلم:** `γ` بلا وحدة؛ ذكر «kg» له خطأ وحدة (−١).
