# الوحدة ٤ · الدرس ١: النماذج الذرية والطيوف — نموذج بور لذرة الهيدروجين

> **وزن الوحدة ٤ في ٢٠٢٦: ٢٠ درجة فقط (س٢ بند امتصاص الأشعة السينية).** بور مرشح دائم لبند «اذكر/عرّف/استنتج». المصادر: الكتاب ص ١٩٨–٢٠٩ · الأستاذ فداء «الكهرباء ٢» (النماذج الذرية: س١–س٧ + تمارين ص ٢٠٧–٢٠٨). الرموز: `k = 1/(4πε0) = 9×10⁹`، `ε0` سماحية الخلاء، `e = 1.6×10⁻¹⁹ C`، `me = 9.1×10⁻³¹ kg`، `h = 6.63×10⁻³⁴ J·s` ثابت بلانك، `ħ = h/2π`، `rn` نصف قطر المدار `n`، `En` الطاقة الكلية، `1 eV = 1.6×10⁻¹⁹ J`.
> حالة: **مسوّدة** · `approved:false`.

---

## 🔑 قبل أن تبدأ
**تحتاج:** قانون كولون `F = k·e²/r²`، الحركة الدائرية المنتظمة `a = v²/r`، الطاقة الكامنة الكهربائية `Ep = −k·e²/r`، العزم الحركي `L = m·v·r`، `E = h·f = h·c/λ`.

**سؤال توقّع:**
> (أ) لماذا لا يسقط الإلكترون على النواة رغم أنه شحنة تدور (وبالكلاسيكية يجب أن يشع ويفقد طاقة)؟ (ب) طاقة الإلكترون في مداره **سالبة** — ماذا يعني ذلك؟ (ج) هل يمكن لذرة هيدروجين أن تمتص فوتوناً طاقته `5 eV` وهي في حالتها الأساسية؟

## 📖 الفكرة

### ١. لماذا احتجنا بور؟ [الكتاب ص ٢٣٢ / أستاذ]
بالفيزياء التقليدية: الإلكترون الدائر شحنة متسارعة ⇒ يشع ⇒ يفقد طاقة تدريجياً ⇒ يقترب من النواة ويستقر فيها — **وهذا لا يحدث في الطبيعة**؛ كما تعجز الكلاسيكية عن تفسير **الطيوف الخطية**. **مبادئ بور (تكميم الضوء لتفسير الطيوف) [أستاذ س١]:**
1. **تغير طاقة الذرة مكمّم.**
2. لا توجد الذرة إلا في **حالات طاقة محددة** (سويات).
3. عند انتقال الإلكترون في ذرة مثارة من سوية `Ep` إلى سوية أدنى `En` تصدر الذرة **فوتوناً** طاقته **`h·f = Ep − En`**.

### ٢. القوى على إلكترون الهيدروجين [أستاذ س٢]
بإهمال التجاذب الكتلي (لصغره): **القوة الكهربائية** `F = k·e²/r²` (جذب البروتون) هي القوة المركزية؛ وفي جملة الإلكترون تُوازنها **قوة العطالة النابذة** `me·v²/r`.

### ٣. فرضيات بور الثلاث [أستاذ]
1. **الأولى:** حركة الإلكترون حول النواة **دائرية منتظمة**: `k·e²/r² = me·v²/r`.
2. **الثانية:** **العزم الحركي مكمّم**: `me·v·r = n·h/(2π) = nħ`، `n = 1, 2, 3, …` رقم المدار.
3. **الثالثة:** لا يصدر الإلكترون ولا يمتص طاقة ما بقي في مداره؛ **يمتص** كمية محددة عند الانتقال إلى مدار **أبعد**؛ **يصدر** عند الانتقال إلى مدار **أقرب**: `|ΔE| = h·f`.
(جواب سؤال التوقّع أ: بالفرضية الثالثة — المدارات المستقرة لا إشعاع فيها؛ بور **افترض** ذلك ولم يفسره، والتفسير جاء لاحقاً مع ميكانيك الكم.)

## 🧮 البرهان المُرقَّم ١ — الطاقة الكلية للإلكترون [أستاذ س٣ / الكتاب ص ٢٠٠]
| # | | درجة |
|---|---|---|
| ① | الفرض الأول: `k·e²/r² = me·v²/r` ⇒ `me·v² = k·e²/r` | ٤ |
| ② | الطاقة الحركية: `Ek = ½me·v² = k·e²/(2r)` | ٣ |
| ③ | الطاقة الكامنة الكهربائية (جملة إلكترون–نواة): `Ep = −k·e²/r` | ٣ |
| ④ | الكلية: `E = Ek + Ep = k·e²/2r − k·e²/r` ⇒ **`E = −k·e²/(2r)`** | ٤ |

**تفسير الإشارة [أستاذ س٦]:** القسم **السالب** هو الكامنة (تأثر الإلكترون بحقل النواة)، القسم **الموجب** الحركية (دورانه)؛ المجموع **سالب** لأنه **طاقة ارتباط** — يلزم تقديم `|E|` لتحرير الإلكترون (جواب سؤال التوقّع ب). `|E|` تتناسب عكساً مع `n²`؛ تزداد `E` (تقترب من الصفر) بازدياد `n` وتنعدم في اللانهاية ⇒ **إلكترون حر**.

## 🧮 البرهان المُرقَّم ٢ — نصف قطر المدار ونصف قطر بور [أستاذ س٤ / الكتاب ص ٢٠١]
| # | | درجة |
|---|---|---|
| ① | الفرض الثاني: `me·v·r = nh/2π` ⇒ `v = nh/(2π·me·r)` | ٤ |
| ② | من ①(البرهان ١): `me·v² = k·e²/r` ⇒ نعوّض: `me·n²h²/(4π²me²r²) = k·e²/r` | ٤ |
| ③ | ⇒ **`rn = n²·h²/(4π²·k·me·e²)`** — يتناسب مع `n²` | ٤ |
| ④ | للهيدروجين `n = 1`: **`r1 = 0.53×10⁻¹⁰ m = 0.53 Å` نصف قطر بور** ⇒ `rn = n²·r1` | ٣ |

## 🧮 البرهان المُرقَّم ٣ — سويات الطاقة `En` [أستاذ س٥ / الكتاب ص ٢٠٢]
| # | | درجة |
|---|---|---|
| ① | `E = −k·e²/2r` ونعوّض `rn` | ٣ |
| ② | **`En = −2π²·k²·me·e⁴/(n²h²)`** | ٤ |
| ③ | للهيدروجين `n = 1`: **`E1 = −13.6 eV = −21.76×10⁻¹⁹ J`** ⇒ **`En = −13.6/n² eV`** | ٤ |
| ④ | `E2 = −3.4`، `E3 = −1.51`، `E4 = −0.85 eV`، `E∞ = 0` ⇒ إلكترون حر | ٣ |

**طاقة التأين (الكتاب ص ٢٠٢):** أقل طاقة تنقل الإلكترون من الأساسية إلى `E∞ = 0`: **`Ei = 13.6 eV`**.

> **⚠️ الخطأ الشائع ١:** «الطاقة تقل كلما ابتعد الإلكترون». `−3.4 > −13.6`: الطاقة **تزداد** (تقل سلبية) مع `n`؛ ما **يقل** هو `|E|` = طاقة الارتباط. في المقارنة انتبه للإشارة.
> **⚠️ الخطأ الشائع ٢ (جواب سؤال التوقّع ج):** **لا** تمتص الذرة `5 eV` من الأساسية لأن لا سوية عند `−8.6 eV`؛ الامتصاص يكون **فقط** بطاقات تساوي فرق سويتين (`10.2, 12.09, 12.75 …`) أو `≥ 13.6` (تأين). **الفوتون كله أو لا شيء.**

### ٤. الطيوف الذرية [أستاذ س٧ / الكتاب ص ٢٠٤–٢٠٦]
**التعليل:** سويات مثارة عديدة؛ الانتقال من أعلى إلى أخفض يُصدر فوتوناً؛ الانتقالات المختلفة ⇒ تواترات مختلفة ⇒ أطوال موجات مختلفة ⇒ **خطوط طيفية**. **الطيف الذري لعنصر:** سلسلة التواترات الضوئية الصادرة عن ذراته (بصمة العنصر).
| النوع | الوصف | أمثلة |
|---|---|---|
| **مستمر** | جميع الألوان مناطق متجاورة بلا فواصل | ضوء الشمس، مصباح التنغستن — **الأجسام الصلبة الساخنة** |
| **متقطع (خطي/عصابات)** | خطوط أو عصابات منفصلة | طيف الهيدروجين، مصباح بخار الزئبق — **المصابيح الغازية** |

**سلاسل الهيدروجين:** الإلكترون يعود من السويات العليا إلى:
- `n = 1` ⇒ **ليمان** (فوق بنفسجي) · `n = 2` ⇒ **بالمر** (مرئي) · `n = 3` ⇒ **باشن** (تحت أحمر).
**طول موجة خط:** `1/λ = (Ep − En)/(hc)`؛ بالـeV: `λ(nm) ≈ 1240/ΔE(eV)`.

## ✍️ مثال محلول ١ — انتقال وإصدار
انتقل إلكترون الهيدروجين من `n = 3` إلى `n = 2`. `h = 6.63×10⁻³⁴`، `c = 3×10⁸`.
| | | |
|---|---|---|
| السويتان | `E3 = −13.6/9 = −1.51 eV` · `E2 = −3.4 eV` | ٣+٣ |
| طاقة الفوتون | `ΔE = E3 − E2 = 1.89 eV = 3.02×10⁻¹⁹ J` | ٥+٣+١+١ |
| التواتر | `f = ΔE/h = 4.56×10¹⁴ Hz` | ٥+٣+١+١ |
| الطول الموجي والسلسلة | `λ = c/f = 6.58×10⁻⁷ m = 658 nm` — أحمر، **سلسلة بالمر** (Hα) | ٥+٣+١+١ +٢ |
| نصف قطر المدار ٣ | `r3 = 9×0.53 = 4.77 Å` | ٣+١ |

## ✍️ مثال ٢ — أكمل: التأين والسرعة
- طاقة تأين ذرة هيدروجين في السوية `n = 2`: `▢ eV`.
- سرعة الإلكترون في المدار الأول: من `me·v² = k·e²/r1` ⇒ `v1 = √(9×10⁹×(1.6×10⁻¹⁹)²/(9.1×10⁻³¹×0.53×10⁻¹⁰)) = ▢ m·s⁻¹` — وهل يلزم تصحيح نسبي؟
