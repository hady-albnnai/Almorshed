# الوحدة ٤ · الدرس ٣: الفوتون والفعل الكهرضوئي — الأشعة السينية — الليزر

> **في ٢٠٢٦: س٢ بند «امتصاص الأشعة السينية» (٢٠ درجة، اختياري).** الكهرضوئي هو المسألة الحسابية الأكثر ظهوراً في هذه الوحدة تاريخياً. المصادر: الكتاب ص ٢٣٠–٢٥٣ · الأستاذ فداء «الكهرباء ٢» (نظرية الكم + كهرضوئي س١–س٣ + الخلية + ص ٢٣٧–٢٣٨ + ٣٧ عامة؛ سينية س١–س٩؛ ليزر س١–س٢ + الجدول). الرموز: `h`، `f`، `λ`، `c`، `E = hf` طاقة الفوتون، `p = h/λ` كمية حركته، `Ws = h·f0 = hc/λ0` طاقة الانتزاع (`f0` تواتر العتبة، `λ0` طول موجة العتبة)، `Ek max`، `U0` كمون الإيقاف، `Is` تيار الإشباع، `P` استطاعة الحزمة، `N` عدد الفوتونات/ثانية، `UAC` توتر أنبوب كوليدج، `λmin`.
> حالة: **مسوّدة** · `approved:false`.

## 🔑 قبل أن تبدأ
**تحتاج:** `Ws`، `v = √(2eU/m)` (L2)، سويات بور (L1)، `E = hf = hc/λ`، نظرية الطاقة الحركية.

**سؤال توقّع:**

## 📖 الفكرة

### أ. نظرية الكم والفوتون [أستاذ / الكتاب ص ٢٣٢]
- **فرضية بلانك:** الضوء والمادة يتبادلان الطاقة بكميات منفصلة «**كمات**» طاقة كل منها **`E = h·f`**.
- **فرضية أينشتاين:** الحزمة الضوئية مكونة من **فوتونات** طاقة كل منها `hf`؛ التبادل مع المادة بامتصاص أو إصدار فوتونات.
**خواص الفوتون:** ① جسيم **يواكب موجة كهرطيسية** تواترها `f` ② **عديم الشحنة** ③ يتحرك بسرعة الضوء ④ طاقته `E = hf = hc/λ` ⑤ كمية حركته **`p = E/c = h/λ`** (من النسبية: `E = pc` لجسيم عديم الكتلة السكونية).

### ب. الفعل الكهرضوئي [أستاذ / الكتاب ص ٢٣٣–٢٣٨]
**التعريف:** انتزاع الإلكترونات الحرة من المادة عند تعرضها لإشعاعات كهرطيسية مناسبة.
**تجربة هرتز (صفيحة توتياء على كاشف كهربائي):**
| | الملاحظة | التفسير |
|---|---|---|
| مشحونة **سالباً** + ضوء زئبق | تتقارب الوريقتان حتى تنطبقا | تُنتزع إلكترونات بالفعل الكهرضوئي، تتنافر مع الشحنة السالبة فتبتعد ⇒ تفقد الصفيحة شحنتها |
| + **لوح زجاجي** بين المصباح والصفيحة | لا يتغير الانفراج | الزجاج **يمتص فوق البنفسجي** المسؤول عن الانتزاع؛ المرئي وتحت الأحمر لا تكفي طاقتهما |
| مشحونة **موجباً** + ضوء | لا يتغير | المنتزعة **يُعاد جذبها** بالشحنة الموجبة |

**شرح أينشتاين — ثلاث إمكانيات:** الفوتون يقدّم **كامل طاقته** لإلكترون واحد:
1. `hf = Ws` ⇒ ينتزع بطاقة حركية **معدومة**؛ `f0 = Ws/h` **تواتر العتبة**، `λ0 = hc/Ws` **طول موجة العتبة**.
2. `hf > Ws` ⇒ ينتزع بطاقة حركية `Ek = hf − Ws`.
3. `hf < Ws` ⇒ يكتسب طاقة حركية ويبقى مرتبطاً (**لا ينتزع**).

## 🧮 البرهان المُرقَّم ١ — معادلة أينشتاين وسرعة الخروج [أستاذ س٢]
| # | | درجة |
|---|---|---|
| ① | حفظ الطاقة عند امتصاص فوتون: طاقة الفوتون = طاقة الانتزاع + الطاقة الحركية العظمى للإلكترون المنتزع | ٤ |
| ② | **`h·f = Ws + ½·me·v²max`** — معادلة أينشتاين | ٤ |
| ③ | مع `Ws = hf0`: `½me v²max = h(f − f0) = hc(1/λ − 1/λ0)` | ٣ |
| ④ | **`vmax = √(2h(f − f0)/me)`** — تزداد بزيادة `f` **فقط** | ٤ |

**لماذا انتصر أينشتاين على النظرية الموجية؟ [أستاذ س٣] — جدول المواجهة:**
| الملاحظة التجريبية | أينشتاين (فوتون) | الموجية الكلاسيكية |
|---|---|---|
| لا يحدث الفعل إذا `f < f0` مهما كانت الشدة | ✓ الفوتون الواحد `hf < Ws` | ✗ يحدث عند كل التواترات (تتراكم الطاقة) |
| `Ek max` **لا** تزداد بزيادة الشدة | ✓ الشدة = عدد الفوتونات لا طاقتها | ✗ تزداد بالشدة |
| `Ek max` تزداد بزيادة `f` | ✓ `hf − Ws` | ✗ لا علاقة بالتواتر |
| الانتزاع **آني** | ✓ امتصاص فوتون واحد | ✗ يلزم زمن تراكم |
(جواب سؤال التوقّع أ.)

> **⚠️ الخطأ الشائع ١:** «الضوء الأشد يعطي إلكترونات أسرع». الشدة ⇒ **عدد** الإلكترونات (تيار الإشباع) فقط؛ **السرعة** يحددها التواتر. هذا هو قلب الدرس وأكثر مشتت يُستعمل في MCQ.

### ج. الخلية الكهرضوئية والمنحني `I(U)` [أستاذ / الكتاب ص ٢٣٦]
حبابة زجاجية مخلاة؛ **المهبط `C`** مغطى بطبقة رقيقة من **معدن قلوي** (طاقة انتزاع صغيرة) يتلقى الضوء؛ **المصعد `A`** حلقة أو شبكة.
| `UAC` | ما يحدث |
|---|---|
| **عكسي كبير** (`UAC ≤ −U0`) | كمون المهبط أعلى؛ القوة الكهربائية تعيد الإلكترونات إلى المهبط ⇒ **`I = 0`** |
| **عكسي صغير** (`−U0 < UAC < 0`) | بعض الإلكترونات (الأسرع) تصل ⇒ تيار يزداد كلما صغر `|UAC|` |
| **مباشر** (`UAC > 0`) | المصعد يسرّع الإلكترونات ⇒ يزداد `I` حتى **`Is` تيار الإشباع**: كل المنتزعة تصل |
**كمون الإيقاف `U0`:** أقل توتر عكسي يكفي لمنع وصول المنتزعة إلى المصعد (جعل التيار معدوماً): **`e·U0 = ½me v²max = hf − Ws`**. **لا يتعلق بالشدة**، يتعلق بـ`f`.
**تيار الإشباع:** يزداد بزيادة **استطاعة الحزمة** (عدد أكبر من الفوتونات ⇒ إلكترونات أكثر): `N = P/(hf)` فوتون/ثانية؛ إذا انتزع كل فوتون إلكتروناً: `Is = N·e` (والمردود الكمي `= (Is/e)/N`).

### د. الأشعة السينية [أستاذ س١–س٩ / الكتاب ص ٢٤٠–٢٤٥]
**أنبوب كوليدج:** زجاجي مخلى تخلية شديدة (`~10⁻⁶ mmHg`)؛ **سلك تنغستين** يُسخَّن للتوهج؛ **مهبط معدني مقعر** يحيط به يجمع الحزمة على **الهدف** (مصعد مقابل) من معدن ثقيل عالي الانصهار (**موليبدن**/تنغستن) مائل بزاوية على المحور، مثبت على أسطوانة نحاسية موصولة **بمبرّد**.
**آلية التوليد:** تُنتزع الإلكترونات من السلك **بالفعل الكهرحراري** ⇒ تُسرَّع بتوتر عالٍ `UAC` ⇒ تصدم ذرات الهدف؛ **بعضها** ينتزع إلكتروناً من **طبقة داخلية** مخلفاً ثقباً ⇒ إلكترون من طبقة أعلى يملؤه **مصدراً فوتوناً عالي الطاقة = أشعة سينية**؛ **الجزء الأكبر** تتحول طاقته الحركية إلى **حرارة** في الهدف ⇒ **لذلك المبرّد** [س٥].

## 🧮 البرهان المُرقَّم ٢ — أصغر طول موجة [أستاذ س٢ / الكتاب ص ٢٤٣]
| # | | درجة |
|---|---|---|
| ① | طاقة الإلكترون المسرَّع عند وصوله للهدف: `Ek = e·UAC` | ٣ |
| ② | أعلى طاقة فوتون = تحول **كامل** `Ek` إلى فوتون واحد: `h·fmax = e·UAC` | ٤ |
| ③ | `fmax = c/λmin` ⇒ **`λmin = h·c/(e·UAC)`** | ٤ |
| ④ | تتعلق `λmin` بـ`UAC` **فقط** (لا بمادة الهدف ولا بتيار التسخين) | ٢ |
**[الكتاب ص ٢٤٣]** الزالقة (ق) تغير `UAC` ⇒ تغير **طاقة** الأشعة (قساوتها)؛ الزالقة (م) تغير حرارة السلك ⇒ عدد الإلكترونات ⇒ **شدة** الأشعة (جواب سؤال التوقّع ب: التوتر ⇒ الطاقة؛ التسخين ⇒ الكمية).

**الطبيعة والخواص (اذكر ٥):** ① **أمواج كهرطيسية** أطوالها قصيرة جداً (`10⁻¹¹ – 10⁻⁸ m`) ⇒ طاقة عالية، تنتشر بسرعة الضوء ② **قدرة عالية على النفاذ** بسبب قصر `λ` ③ لا تصدر إلا من ذرات **العناصر الثقيلة** ④ تشبه الضوء: انتشار، انعكاس، تداخل، انعراج ⑤ **لا شحنة ⇒ لا تتأثر بـ`E` ولا `B`** ⑥ تسبب تألق المواد ⑦ تؤثر في الأنسجة الحية ⑧ تؤين الغازات.

**الامتصاص والنفاذ (س٢ ٢٠٢٦):** تزداد النسبة **الممتصة** وتقل **النافذة** بازدياد:
1. **ثخن المادة**.
2. **كثافة المادة** (عظم، رصاص، ذهب ⇒ امتصاص جيد؛ خشب، بلاستيك، جلد ⇒ ضعيف) — أساس التصوير الشعاعي.
3. **نقصان طاقة الأشعة** (تمتص اللينة أكثر).
**نوعان:** **لينة** (`λ` أطول، طاقة منخفضة، امتصاص كبير، نفوذ قليل) · **قاسية** (`λ` أقصر، طاقة عالية، امتصاص قليل، نفوذ كبير).

**موازنات [أستاذ س٨–س٩]:**
| | الأشعة السينية | الفعل الكهرضوئي |
|---|---|---|
| المبدأ | **ترد إلكترونات** سريعة ⇒ **تصدر فوتونات** | **ترد فوتونات** ⇒ **تتحرر إلكترونات** (عكسه) |

| | مهبطية | سينية |
|---|---|---|
| الطبيعة | إلكترونات | أمواج كهرطيسية/فوتونات عالية الطاقة |
| في `E`، `B` | تنحرف (شحنة سالبة متحركة) | لا تتأثر (لا شحنة) |

### هـ. الليزر [أستاذ س١–س٢ / الكتاب ص ٢٤٦–٢٥٢]
**LASER = تضخيم الضوء بالإصدار المحثوث للأشعة.**
| | الإصدار التلقائي | الإصدار المحثوث |
|---|---|---|
| متى | ذرة مثارة تعود لسوية أدنى **بوجود حزمة أو بدونها** | **فقط** عند تعرض الذرة المثارة لفوتون طاقته `hf = E2 − E1` |
| الاتجاه | جميع الاتجاهات | **نفس جهة** الفوتون الوارد |
| الطاقة/التواتر | `hf = ΔE` | نفس طاقة وتواتر الوارد ⇒ **فوتونان متطابقان** |
| الطور | أي قيمة | **يطابق** طور الوارد |
**خواص حزمة الليزر:** ① **وحيدة اللون** (تواتر واحد) ② **مترابطة بالطور** (فوتونات المحثوث بطور الفوتون الحاث) ③ **انفراجها صغير** (المقطع لا يتوسع بالابتعاد) — (جواب سؤال التوقّع ج: كل الفوتونات بنفس الاتجاه والطور).
**مكونات الجهاز:**
1. **الوسط الفعال (المضخم):** `N*` ذرات مثارة، `N` أساسية. الامتصاص `∝ N`، المحثوث `∝ N*`. **`N* > N` (انقلاب التوزع)** ⇒ المحثوث > الممتص ⇒ الحزمة **تتضخم** ⇒ يصلح لليزر؛ `N* < N` ⇒ تضعف ⇒ لا يصلح.
2. **حجرة التضخيم (المرنان):** مرآتان حول الوسط؛ إحداهما **عاكسة كلياً** والأخرى **جزئياً** تمرر جزءاً = **الحزمة الليزرية**.
3. **جملة الضخ:** لأن المحثوث يعيد الذرات للأساسية فلا بد من مؤثر خارجي يعوّض الإثارة. **طرائق:** ضوئي (مصابيح ومّاضة — الياقوتي)، كهربائي (تفريغ في غاز — الغازي)، كيميائي (تفاعل بين مكونات الوسط، بلا مصدر خارجي).
**أنواع:** غازي (He–Ne، مخابر)، صلب (نصف ناقل، اتصالات)، ياقوتي، سائل (كلوريد الألمنيوم في الكحول). **استخدامات:** طب (عيون، جلد)، أقراص مدمجة وباركود، لحام وقص، توجيه صواريخ.

## ✍️ مثال محلول ١ — خلية كهرضوئية (نمط مسألة تاريخية) [أستاذ ٣٧ عامة + ص ٢٣٨]
مهبط من البوتاسيوم `Ws = 2.2 eV` يُضاء بضوء `λ = 400 nm`؛ استطاعة الحزمة `P = 3 mW`؛ `h = 6.63×10⁻³⁴`، `c = 3×10⁸`، `e = 1.6×10⁻¹⁹`، `me = 9.1×10⁻³¹`.
| | | |
|---|---|---|
| (١) طاقة الفوتون | `E = hc/λ = 6.63×10⁻³⁴×3×10⁸/4×10⁻⁷ = 4.97×10⁻¹⁹ J = 3.1 eV` | ٥+٣+١+١ |
| (٢) هل يحدث الفعل؟ | `3.1 > 2.2` ⇒ نعم؛ أو `λ0 = hc/Ws = 565 nm > 400 nm` ✓ | ٣+٣ |
| (٣) `Ek max` و`vmax` | `Ek = 3.1 − 2.2 = 0.9 eV = 1.44×10⁻¹⁹ J` ⇒ `v = √(2Ek/me) = 5.6×10⁵ m·s⁻¹` | ٥+٣+١+١ ×٢ |
| (٤) كمون الإيقاف | `eU0 = Ek ⇒ U0 = 0.9 V` | ٥+٣+١+١ |
| (٥) عدد الفوتونات/ثانية | `N = P/E = 3×10⁻³/4.97×10⁻¹⁹ = 6×10¹⁵ s⁻¹` | ٥+٣+١+١ |
| (٦) تيار الإشباع إذا انتزع كل فوتون إلكتروناً | `Is = Ne = 9.7×10⁻⁴ A ≈ 1 mA` | ٥+٣+١+١ |
| (٧) نضاعف `P` | `U0` **لا يتغير**، `Is` **يتضاعف** | ٣+٣ |
**[أستاذ طر٢]** بديل لـ(٤): نظرية الطاقة الحركية بين المهبط والمصعد: `0 − ½mv² = −eU0` لأن الإلكترون يصل المصعد بسرعة معدومة.
