## 📖 الفكرة

### ١. الكواكب والنجوم والمجموعة الشمسية [كتاب ص ٢٥٦]
**تمييز الكوكب عن النجم بالرصد:** إشعاع الكواكب أكثر **ثباتاً** (النجوم تتلألأ)؛ مواقع الكواكب **متغيرة** بين النجوم الثابتة التشكيلات؛ بالتلسكوب تبدو الكواكب أقراصاً أوضح بينما تبقى النجوم **نقاطاً**. المجموعة الشمسية: ٨ كواكب، ٤ صخرية (القريبة) و٤ **غازية (البعيدة)**.

### ٢. مصدر طاقة النجوم [كتاب ص ٢٥٦–٢٥٧]
النجوم أساساً هيدروجين وهيليوم؛ مع الزمن **يزداد الهيليوم ويقل الهيدروجين وتقل كتلة النجم** ⇒ **اندماج نووي**: يندمج الهيدروجين ليعطي هيليوماً، و**النقص في الكتلة يتحول إلى طاقة `E = Δm·c²`** (جواب سؤال التوقّع أ). **نظرية السديم:** ينهار سديم (سحابة غاز وجسيمات) تحت جاذبيته ⇒ ضغط وحرارة مرتفعان ⇒ يبدأ الاندماج.

## 🧮 حساب مُرقَّم ١ — النقص في كتلة الشمس كل ثانية [كتاب ص ٢٥٦–٢٥٧]
معطى: طاقة تصل كل `1 m²` من سطح الأرض `≈ 1000 J` كل ثانية وهي **٧٠٪** من الوارد (الباقي يمتصه الغلاف أو يرتد)؛ بعد الشمس `d = 1.5×10¹¹ m`.
| # | | |
|---|---|---|
| ① | الاستطاعة الواردة فوق الغلاف لكل `m²`: `P1 = 1000/0.7 ≈ 1430 W·m⁻²` | «مفترض» أن رقم الكتاب 1000 — غير مقروء بدقة |
| ② | الطاقة الكلية في الثانية = على سطح كرة نصف قطرها `d`: `P = P1·4πd² = 1430×4π×(1.5×10¹¹)² ≈ 4×10²⁶ W` | |
| ③ | `Δm = E/c² = 4×10²⁶/(9×10¹⁶) ≈ 4.4×10⁹ kg` **كل ثانية** (~٤ ملايين طن) | |

### ٣. الإشعاع النجمي والطيوف [كتاب ص ٢٥٧–٢٥٨]
لون النجم يتعلق بدرجة حرارته (الطول الموجي المهيمن)؛ من **طيف** النجم وشدة إضاءته وحركته نحدد كتلته وعمره وتركيبه الكيميائي. كثير من النجوم **ثنائية** تدور حول بعضها (الإزار والسها في مقبض الدب الأكبر).

### ٤. أثر دوبلر والانزياح نحو الأحمر [كتاب ص ٢٥٨–٢٥٩]
## 🧮 البرهان المُرقَّم ٢ — الطول الموجي عند ابتعاد المنبع
| # | | |
|---|---|---|
| ① | منبع ساكن: خلال دور `T` تشغل الموجة مسافة `λ = v_w·T` (`v_w` سرعة الموجة) | |
| ② | منبع **يبتعد** بسرعة `v`: خلال `T` يبتعد المنبع `v·T` فتُمدّ الموجة: **`λ′ = λ + v·T = λ(1 + v/v_w)`** ⇒ `λ′ > λ` | |
| ③ | للضوء `v_w = c`: **`Δλ/λ = (λ′ − λ)/λ = v/c`** ⇒ **`v = c·Δλ/λ`** | |
| ④ | منبع **يقترب**: `λ′ = λ(1 − v/c)` ⇒ `λ′ < λ` ⇒ **انزياح نحو الأزرق** [كتاب ثانياً ٢ ص ٢٦٧] | |
**الأحمر** هو أطول موجة مرئية ⇒ ابتعاد المنبع الضوئي ⇒ **انزياح الطيف نحو الأحمر** (جواب سؤال التوقّع ب: **تبتعد**). (مثال صوتي: بوق السيارة يصير أغلظ بعد مرورها.)

### ٥. قانون هابل [كتاب ص ٢٥٩–٢٦٠]
لاحظ هابل أن طيف المجرات ينزاح نحو الأحمر **أكثر كلما كانت أبعد** ⇒ سرعة الابتعاد تتناسب مع البعد:
> **`v = H0·d`** — `H0` ثابت هابل (≈ `68–70 km·s⁻¹·Mpc⁻¹` من الخط البياني: `680 km/s` عند `10 Mpc`).
بالواحدات الدولية: `1 Mpc = 10⁶×3.26×9.46×10¹⁵ ≈ 3.08×10²² m` ⇒ `H0 ≈ 68×10³/3.08×10²² ≈ 2.2×10⁻¹⁸ s⁻¹`.

## ✍️ مثال محلول ١ — بعد مجرة من انزياحها [كتاب ص ٢٥٩–٢٦٠]
خط الهيدروجين في مجرة انزاح بنسبة `Δλ/λ = 0.034` («مفترض»؛ رقم الكتاب غير مقروء — النتيجة الواردة «`0.466` مليار سنة» تفرض نسبة قريبة من هذه).
| | | |
|---|---|---|
| السرعة | `v = c·Δλ/λ = 3×10⁸×0.034 ≈ 1.02×10⁷ m·s⁻¹` | ٥+٣+١+١ |
| البعد | `d = v/H0 = 1.02×10⁷/2.2×10⁻¹⁸ ≈ 4.6×10²⁴ m` | ٥+٣+١+١ |
| بالسنين الضوئية | `d/9.46×10¹⁵ ≈ 4.9×10⁸ ly` ⇒ ما نراه حدث قبل **≈ ٠.٥ مليار سنة** | ٣+١ |

### ٦. الانفجار الأعظم وتمدد الكون [كتاب ص ٢٦١–٢٦٢]
الانزياح نحو الأحمر لكل المجرات ⇒ **كلها تبتعد عن بعضها** ⇒ **الفضاء يتمدد كبالون يُنفخ**. بتراجع زمني: الكون كان **نقطة منفردة** كثافتها وحرارتها فوق الخيال ⇒ **الانفجار الأعظم قبل ≈ ١٣.٨ مليار سنة** ⇒ جسيمات أولية ⇒ ذرات وجزيئات وغبار ⇒ نجوم ومجرات؛ التوسع مستمر.
**الأسس الفيزيائية الثلاثة:** ① الانزياح نحو الأحمر لطيف المجرات ② **تشويش راديوي ضعيف منتظم من جميع الاتجاهات** بالشدة المتوقعة لإشعاع الانفجار (الخلفية الكونية) ③ **كميات هائلة من الهيدروجين والهيليوم**: هيليوم الشمس ثلاثة أضعاف ما يمكن أن يولّده اندماجها ⇒ مصدر أسخن بكثير: **الدقائق الأولى من الانفجار**.

## 🧮 حساب مُرقَّم ٣ — عمر الكون التقريبي من هابل [كتاب ص ٢٦١]
| # | | |
|---|---|---|
| ① | `d` هي المسافة التي قطعتها المجرة منذ الانفجار (كانت كل المجرات في النقطة نفسها) بسرعة `v` ثابتة: `d = v·t` | |
| ② | `v = H0 d` ⇒ `d = H0·d·t` ⇒ **`t = 1/H0`** | |
| ③ | `t = 1/(2.2×10⁻¹⁸) ≈ 4.5×10¹⁷ s ≈ 1.4×10¹⁰` سنة ≈ **١٤ مليار سنة** ✓ | |

**المجرات:** المجرة نظام كوني من تجمع هائل من النجوم والغبار والغازات مرتبطة بالتجاذب وتدور حول مركز مشترك؛ ≈ `10¹¹` مجرة في الكون المنظور؛ **درب التبانة** > `10¹¹` نجم، قطرها ≈ `10⁵ ly`. تلسكوب هابل الفضائي يدور خارج الغلاف الجوي.

### ٧. سرعة الإفلات والثقوب السوداء [كتاب ص ٢٦٣–٢٦٥]
## 🧮 البرهان المُرقَّم ٤ — السرعة الكونية الثانية ونصف قطر شفارتزشيلد
| # | | |
|---|---|---|
| ① | ليفلت جسم من جاذبية جرم كتلته `M` نصف قطره `R`: طاقته الحركية ≥ طاقة الجذب الكامنة: `½mv² = GMm/R` | |
| ② | **`vesc = √(2GM/R)`** — **السرعة الكونية الثانية** (لا تتعلق بـ`m`) | |
| ③ | للأرض: `g = GM/R²` ⇒ `GM = gR²` ⇒ `vesc = √(2gR) = √(2×10×6.4×10⁶) ≈ 11.3×10³ m·s⁻¹ ≈ 11.2 km/s` | |
| ④ | كلما **صغر `R`** (وزادت الكثافة) بكتلة ثابتة ازدادت `vesc`؛ لكن لا سرعة تتجاوز `c` ⇒ إذا `vesc = c`: `c² = 2GM/Rs` ⇒ **`Rs = 2GM/c²` نصف قطر شفارتزشيلد** | |
| ⑤ | جرم نصف قطره `≤ Rs` ⇒ **لا شيء يفلت حتى الضوء** ⇒ **ثقب أسود**؛ الحد الذي لا إفلات بعده: **أفق الحدث** | |

**السرعة الكونية الأولى** = السرعة المدارية (النابذة = الجذب): `mv1²/R = GMm/R²` ⇒ `v1 = √(GM/R)` ⇒ **`vesc = √2·v1`** [كتاب ثانياً ٣ ص ٢٦٧].
**الثقب الأسود:** حيّز كثافته هائلة بحيث لا يمكن لشيء الإفلات من جاذبيته حتى الضوء ⇒ يبدو **غير مرئي**. كيف يجذب الضوء وهو بلا كتلة سكونية؟ بتكافؤ الطاقة–الكتلة: للفوتون كتلة مكافئة `m = E/c² = hf/c²`.
**رصد الثقوب السوداء (٣ طرق):** ① **سلوك الأجسام المجاورة** — حركات غير متوقعة للنجوم/الغبار/الغاز حول منطقة غير مرئية ② **الانبعاث الإشعاعي** — المادة الدائرة حوله تسخن لملايين الدرجات وتصدر **أشعة سينية** تُرصد بمراصد السينية ③ **عدسة الجاذبية** — (النسبية العامة) الجاذبية تحني الفضاء فيبدو ضوء النجوم الخلفية منحنياً وفي غير مكانه. أول صورة حقيقية لثقب أسود أُعلنت في **١٠ نيسان ٢٠١٩**.

> **⚠️ الخطأ الشائع ١ (جواب سؤال التوقّع ج):** «الثقب الأسود يبتلع كل شيء حوله». الجذب على بعد `r > R` الأصلي **لا يتغير** بانكماش الجرم (`GM/r²` نفسه) ⇒ لو صارت الأرض ثقباً أسود (`Rs ≈ 9 mm`) **يبقى القمر في مداره** [كتاب مسألة ١ ص ٢٦٧]. الثقب الأسود يبتلع فقط ما يقترب من أفق الحدث.
> **⚠️ الخطأ الشائع ٢:** «الثقوب السوداء بالضرورة ذات نصف قطر هائل». لا — **بالضرورة ذات كثافة هائلة** [كتاب أولاً ص ٢٦٧ الجواب c]؛ نصف قطرها قد يكون ميليمترات.

## ✍️ مثال محلول ٢ — الأرض ثقباً أسود [كتاب مسألة ١ ص ٢٦٧]
`R = 6400 km`، `g = 10 m·s⁻²`، `c = 3×10⁸`.
| | | |
|---|---|---|
| `GM` | `GM = gR² = 10×(6.4×10⁶)² = 4.1×10¹⁴ m³·s⁻²` | ٥+٣+١ |
| `Rs` | `Rs = 2GM/c² = 8.2×10¹⁴/9×10¹⁶ ≈ 9.1×10⁻³ m ≈ 9 mm` | ٥+٣+١+١ |
| هل تبتلع القمر؟ | لا — الجذب عند بعد القمر لم يتغير (`M` و`r` نفسهما) | ٤ |
| واقعياً | الأجرام التي تنتهي ثقوباً سوداء نجوم كتلتها > ~١٠ أمثال كتلة الشمس | ٢ |
