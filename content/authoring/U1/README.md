## بنية كل درس (ثابتة)
🔑 قبل أن تبدأ (متطلبات + سؤال توقّع) → 📖 الفكرة (بالـ«لماذا» + ⚠️ أخطاء شائعة تُقدَّم وتُدحض) → 🧮 برهان مُرقَّم بدرجات كل سطر → ✍️ مثالان محلولان بنمط السلم + مثال بخطوات محذوفة → 🎯 اختبر نفسك (مشتتات مشروحة) → 🧾 خلاصة (بطاقات) → ⚖️ خصومات السلم → 📎 جدول المقابلة كتاب↔أستاذ↔امتحان.

## وسوم
- **[أستاذ]** = من ملخصات الأستاذ فداء فقط (غير موجود نصاً في الكتاب).
- **[سلم]** = من سلم التصحيح الوزاري ٢٠٢٦.
- `▢` = خطوة محذوفة يكملها الطالب (fading).
- قيم **مفترضة** معلَّمة صراحة حيث كان رقم الكتاب غير مقروء في النسخة الرقمية — تُثبَّت مع الأستاذ.
