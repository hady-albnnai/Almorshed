# الوحدة ١ · الدرس ٤: ميكانيك السوائل المتحركة

> المصادر: الكتاب ص ٤٣–٥٤ · الأستاذ فداء «السوائل المتحركة» (١٣ صفحة: س١–س٧ + طرق حل ١–٥ + حلول مسائل الكتاب). وزن ٢٠٢٦: اختياري في س٢ (٢٠) ونمط س١ MCQ. الرموز: `Q′` تدفق حجمي، `Q` تدفق كتلي، `s` مساحة المقطع، `v`، `P`، `ρ`, `z`.
> حالة: **مسوّدة** · `approved:false`.

---

## 🔑 قبل أن تبدأ
**تحتاج:** نظرية الطاقة الحركية `ΔEk = ΣW`، عمل قوة ثابتة `W = F·Δx`، الضغط `P = F/s` (Pa = N·m⁻²)، حجم أسطوانة = مساحة القاعدة × الارتفاع، التحويلات (cm² → ×10⁻⁴ m²، L → ×10⁻³ m³).

**سؤال توقّع:**
> تضع إبهامك على فوهة خرطوم فيقفز الماء أبعد. (أ) هل زادت **كمية** الماء الخارجة في الثانية؟ (ب) ضغط الماء **داخل** الفوهة الضيقة أكبر أم أصغر من ضغطه في الخرطوم؟ (الجواب الشائع عن (ب) خاطئ.)

## 📖 الفكرة

### ١. المفاهيم الأساسية (تُسأل كتعاريف — ٥ لكل بند)
- **جسيم السائل:** جزء صغير من السائل أبعاده صغيرة بالنسبة لأبعاد السائل وكبيرة بالنسبة لأبعاد جزيئاته.
- **خط الانسياب:** خط وهمي يبيّن المسار الذي يسلكه جسيم السائل، **يمس شعاع السرعة في كل نقطة** من نقاطه.
  - **[أستاذ] لماذا لا تتقاطع خطوط الانسياب؟** لأن الخط يمس شعاع السرعة؛ تقاطع خطين يعني وجود شعاعي سرعة لجسيم واحد في نقطة واحدة — مستحيل. (سؤال «فسّر» الكتاب ص ٥٢/٢)
- **أنبوب التدفق:** أنبوب وهمي ينتج من اجتماع خطوط الانسياب المارة من منحنٍ مغلق؛ يتحرك السائل داخله ويملؤه تماماً.
- **الجريان المستقر:** سرعة جسيم السائل (وضغطه وكثافته) ثابتة مع الزمن **في النقطة نفسها** من خط الانسياب. **[أستاذ]** ينقسم: **منتظم** (السرعة نفسها في جميع النقاط) / **غير منتظم** (ثابتة في النقطة، تختلف من نقطة لأخرى).
- **معدل التدفق الحجمي** (المنسوب الحجمي، معدل الضخ): `Q′ = V/Δt` (m³·s⁻¹) — حجم السائل العابر للمقطع في واحدة الزمن.
- **معدل التدفق الكتلي:** `Q = m/Δt` (kg·s⁻¹). **[أستاذ]** `Q = ρ·Q′`.

### ٢. صفات السائل المثالي [أستاذ س١ — «اذكر مع الشرح»، ٤ بنود × ٥]
1. **غير قابل للانضغاط:** حجمه ثابت ⇒ كتلته الحجمية ثابتة بمرور الزمن.
2. **عديم اللزوجة:** قوى الاحتكاك الداخلي بين مكوناته مهملة ⇒ لا ضياع في الطاقة.
3. **جريانه مستقر:** جسيماته تحافظ على سرعة ثابتة في النقطة ذاتها من خط الانسياب.
4. **جريانه غير دوراني:** لا تتحرك جسيماته حركة دورانية حول أي نقطة من مجرى الجريان.

### ٣. معادلة الاستمرارية — **لماذا** يسرع السائل في الضيق؟
السائل غير قابل للانضغاط ولا يتجمع داخل الأنبوب ⇒ **الحجم الداخل من `s1` في مدة `Δt` = الحجم الخارج من `s2` في المدة نفسها**.
`V1 = s1·Δx1`، `V2 = s2·Δx2` (أسطوانتان) ⇒ `s1·Δx1/Δt = s2·Δx2/Δt` ⇒
> **`s1·v1 = s2·v2`** ⇒ `Q′ = s·v = const`

**النتيجة:** سرعة الجريان تتناسب **عكساً** مع مساحة المقطع. ضيّقت المقطع للربع ⇒ السرعة ٤ أمثال.
**[أستاذ]** مع `n` فتحات خروج متماثلة (رشاش): `Q′ = s1·v1 = n·s2·v2`.

**جواب سؤال التوقّع (أ):** لا — `Q′` نفسه؛ ما زاد هو السرعة فقط.

**تطبيق «فسّر» (الكتاب ص ٥٢/٣):** عمود الماء من خرطوم موجَّه للأسفل **يضيق** لأن السرعة تزداد بالسقوط (`v2 > v1`) ⇒ `s2 < s1`؛ وموجَّه للأعلى **يتسع** لأن السرعة تنقص. **[أستاذ]**

### ٤. معادلة برنولي — نظرية الطاقة الحركية لواحدة الحجوم
**نص النظرية (يُحفظ حرفياً):** مجموع **الضغط** و**الطاقة الحركية لواحدة الحجوم** و**الطاقة الكامنة الثقالية لواحدة الحجوم** يساوي مقداراً ثابتاً في أي نقطة من نقاط خط الانسياب لسائل جريانه مستقر.
> **`P + ½·ρ·v² + ρ·g·z = const`**

**لماذا الضغط «طاقة لواحدة الحجوم»؟** `Pa = N/m² = N·m/m³ = J/m³` — فالحدود الثلاثة متجانسة، وبرنولي **شكل من أشكال مصونية الطاقة**.

## 🧮 البرهان المُرقَّم — استنتاج معادلة برنولي [أستاذ س٣ — نمط س٢ (٢٠)]

سائل مثالي ينتقل بين المقطع ١ (`s1، P1، v1، z1`) والمقطع ٢ (`s2، P2، v2، z2`) في مدة `Δt`؛ الحجم العابر `ΔV` واحد (غير قابل للانضغاط)، كتلته `m = ρ·ΔV`.

| # | الخطوة | درجة |
|---|---|---|
| ① | نطبّق نظرية الطاقة الحركية بين الدخول والخروج: `ΔEk = ΣW` ⇒ `½·m·v2² − ½·m·v1² = Wtot` | ٤ |
| ② | القوى العاملة: قوة ضغط الدخول `F1 = P1·s1`، قوة ضغط الخروج `F2 = P2·s2`، الثقل `w` | ٣ |
| ③ | `W(F1) = +F1·Δx1 = P1·s1·Δx1 = +P1·ΔV` **(موجب — محرك، بجهة الجريان)** | ٣ |
| ④ | `W(F2) = −F2·Δx2 = −P2·ΔV` **(سالب — مقاوم، يعاكس الجريان)** | ٣ |
| ⑤ | `W(w) = −m·g·(z2 − z1)` (سالب إذا صعد السائل) | ٢ |
| ⑥ | `½·m·v2² − ½·m·v1² = P1·ΔV − P2·ΔV − m·g·z2 + m·g·z1` | ٢ |
| ⑦ | نرتب: `P1·ΔV + ½·m·v1² + m·g·z1 = P2·ΔV + ½·m·v2² + m·g·z2` | ١ |
| ⑧ | نقسم على `ΔV` مع `m/ΔV = ρ`: **`P1 + ½ρv1² + ρgz1 = P2 + ½ρv2² + ρgz2`** ⇒ بالتعميم `P + ½ρv² + ρgz = const` | ٢ |

**⚠️ خصم [أستاذ]:** نسيان الإشارة السالبة لعمل `F2` أو تبريره «مقاوم لأن جهته تعاكس الجريان».

### ٥. الحالات الخاصة والتطبيقات (كل منها سؤال «استنتج» ٥–١٠)

**(أ) أنبوب أفقي** (`z1 = z2`): `P1 + ½ρv1² = P2 + ½ρv2²` ⇒ `P1 − P2 = ½ρ(v2² − v1²)`.
> **كلما زادت سرعة الجريان قلّ ضغط السائل.** — **جواب سؤال التوقّع (ب): الضغط في الفوهة الضيقة أصغر.**

> **⚠️ الخطأ الشائع ١ (الأهم في الدرس):** «السائل في المقطع الضيق مضغوط أكثر». العكس: الضيق ⇒ أسرع (استمرارية) ⇒ **ضغط أقل** (برنولي). السلسلة الثلاثية التي تفسّر كل أسئلة «فسّر» **[أستاذ س٤]:** `s` نقصت ⇒ `v` زادت (استمرارية) ⇒ `P` قلّ (برنولي) ⇒ منسوب السائل في الأنبوب الشاقولي انخفض.

**[أستاذ] عند النقطة `b` (الاختناق) في شكل الكتاب ص ٤٧:** الطاقة الحركية لواحدة الحجوم `½ρv²` **أكبر**، الضغط `P` **أصغر**، الكامنة `ρgz` **متساوية** في a وb وc (المستوي نفسه). الزيادة في الحركية تأتي من نقص الضغط وتعود إليه.

**(ب) سكون السوائل — معادلة المانومتر [أستاذ س٥]:** `v1 = v2 = 0` ⇒ `P1 + ρgz1 = P2 + ρgz2` ⇒ **`P1 − P2 = ρ·g·h`** (النقطة الأعمق ضغطها أكبر).

**(ج) نظرية تورشيللي [أستاذ س٦]:** خزان سطحه `s1` كبير، فتحة جانبية `s2` صغيرة على عمق `h`.
- السطح والفتحة معرّضان للهواء ⇒ `P1 = P2 = P0` **(ملاحظة الأستاذ: أي سطح معرّض للهواء يخضع للضغط الجوي)**.
- `s2 ≪ s1` ⇒ `v2 ≫ v1` ⇒ `v1 ≈ 0`.
- برنولي: `ρgz1 = ½ρv2² + ρgz2` ⇒ `½v2² = g(z1 − z2) = gh` ⇒ **`v2 = √(2gh)`**
- **التفسير:** يخرج السائل بالسرعة التي يصل بها جسم يسقط سقوطاً حراً من ارتفاع `h`. تنطبق على أي فتحة في القعر أو الجدار.

**(د) أنبوب فنتوري [أستاذ س٧ — «أثبت أن الضغط في الجذع أكبر منه في الاختناق»]:**
أفقي ⇒ `P1 − P2 = ½ρ(v2² − v1²)`؛ من الاستمرارية `v2 = (s1/s2)·v1` ⇒
`P1 − P2 = ½ρv1²·[(s1/s2)² − 1]`؛ وبما أن `s1 > s2` فالقوس موجب ⇒ **`P1 > P2`**.
**تطبيق طبي:** تضيّق الشريان بتراكم الدهون ⇒ ينقص ضغط الدم في المقطع المتضيّق دون قيمته اللازمة لمقاومة الضغوط الخارجية.

### ٦. أسئلة «فسّر» الكتاب ص ٥٢ — بالسلسلة الثلاثية
| الظاهرة | التفسير |
|---|---|
| رياح أفقية عند فوهة مدخنة ⇒ يخرج الدخان **أسرع** | هواء سريع فوق الفوهة ⇒ ضغط أقل ⇒ فرق ضغط يسحب الدخان (**برنولي**) |
| اختلاف سرعة النهر في مقاطع مختلفة | `s·v = const` (استمرارية) |
| ماء يندفع بقوة من ثقب صغير في خرطوم | `s` صغيرة ⇒ `v` كبيرة (استمرارية) |
| خراطيم الإطفاء تصل لارتفاعات كبيرة | فوهة ضيقة ⇒ سرعة خروج كبيرة ⇒ `½ρv²` تتحول إلى `ρgz` |
| فتحات موقد الغاز صغيرة | لزيادة سرعة خروج الغاز وضغط أقل يسحب الهواء للاختلاط |
| نغلق جزءاً من فتحة الخرطوم ليصل الماء أبعد | نقص `s` ⇒ زيادة `v` |
| جناح الطائرة: السطح العلوي أكثر تقوساً | الهواء فوقه أسرع ⇒ ضغط أقل ⇒ قوة رفع للأعلى |

## ✍️ مثال محلول ٢ — رشاش بـ٢٥ ثقباً (الكتاب ص ٥٣ المسألة الثالثة)
`s = 10 cm² = 10⁻³ m²`، `v = 50 cm·s⁻¹ = 0.5 m·s⁻¹`، `n = 25`، `s′ = 0.1 cm² = 10⁻⁵ m²`.
(١) `Q′ = s·v = 10⁻³×0.5 = 5×10⁻⁴ m³·s⁻¹`.
(٢) `Q′ = n·s′·v′ ⇒ v′ = 5×10⁻⁴/(25×10⁻⁵) = 2 m·s⁻¹`.

## ✍️ مثال ٣ — أكمل (الكتاب ص ٥٣ المسألة الثانية — مضخة)
`s1 = 10 cm²`، `s2 = 5 cm²` (مفترض)، `Q′ = 2×10⁻³ m³·s⁻¹` (مفترض)، `h = z2 − z1 = 20 m`، `P2 = P0 = 10⁵ Pa` (فوهة الخروج معرّضة للهواء)، `ρ = 10³`, `g = 10`.
(١) `v1 = Q′/s1 = ▢ m·s⁻¹`، `v2 = Q′/s2 = ▢ m·s⁻¹`.
(٢) ضغط الدخول **[أستاذ طرق حل ٣]:** `P1 = P2 + ½ρ(v2² − v1²) + ρgh = 10⁵ + ½×10³×(▢) + 10³×10×20 = ▢ Pa`.

**س٢.** خرطوم `s1 = 4·s2`. سرعة الخروج `v2 =`: (A) `v1/4` · **(B) `4v1`** ✓ · (C) `2v1` ⟵ *لا جذر هنا؛ العلاقة خطية* · (D) `v1`.
**س٣.** رياح أفقية عند فوهة مدخنة ⇒ سرعة خروج الدخان: **(A) تزداد** ✓ · (B) تنقص · (C) دون تغير. التفسير: **برنولي** لا أرخميدس ولا الاستمرارية.

## 🧾 خلاصة
| القانون | ملاحظة |
|---|---|
| `Q′ = V/Δt = s·v` · `Q = m/Δt = ρ·Q′` | حوّل إلى SI أولاً |
| `s1v1 = s2v2` (`= n·s2v2` لعدة فتحات) | `v ∝ 1/s` خطياً |
| `P + ½ρv² + ρgz = const` | ثلاثة حدود بوحدة J·m⁻³ |
| أفقي: `P1 − P2 = ½ρ(v2² − v1²)` | أسرع ⇒ ضغط أقل |
| ساكن: `P1 − P2 = ρgh` | المانومتر |
| تورشيللي: `v = √(2gh)` | `P1 = P2 = P0`، `v1 ≈ 0` |
| فنتوري: `P1 − P2 = ½ρv1²[(s1/s2)² − 1] > 0` | |
| `Wtot = (P1 − P2)ΔV − mgh = ½m(v2² − v1²)` | العمل الميكانيكي |

## ⚖️ خصومات السلم
1. عدم تحويل cm²/L إلى SI ⇒ نتيجة خاطئة بالكامل.
2. إشارة عمل `F2` والثقل في برهان برنولي.
3. «فسّر» بلا العلاقة الرياضية (السؤال ينص: «باستخدام العلاقات الرياضية») ⇒ نصف الدرجة.
4. نسيان `P1 = P2 = P0` أو تبرير `v1 ≈ 0` في تورشيللي.
