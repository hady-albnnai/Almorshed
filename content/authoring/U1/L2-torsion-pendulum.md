# الوحدة ١ · الدرس ٢: الاهتزازات الجيبية الدورانية — نواس الفتل غير المتخامد

> المصادر: الكتاب ص ٢١–٢٨ · الأستاذ فداء «النواسات» (نواس الفتل + طرق حل ١–٦ + ملاحظات الميقاتية) · نمط امتحان ٢٠٢٦ س١/س٢. الرموز كالكتاب: `θ` `θmax` `ω0` `T0` `IΔ` `k` (ثابت الفتل) `Γ` (عزم الإرجاع) `θ′` `θ″`.
> حالة: **مسوّدة** · `approved:false`.

## 🔑 قبل أن تبدأ
**تحتاج من الدرس ١:** بنية برهان «حركة جيبية» (حل مقترح → اشتقاق مرتين → مطابقة → `ω0` → `T0`). **من التحريك الدوراني:** العلاقة الأساسية `ΣΓ = IΔ·θ″`، وعزوم العطالة: ساق حول مركزها `(1/12)·m·l²`، قرص حول محوره `½·m·r²`، كتلة نقطية `m·r²`.

**سؤال توقّع:**
> نواس فتل من قرص معلّق بسلك. (أ) لو استبدلنا القرص بقرص بالكتلة نفسها لكن **قطره ضعف** — هل يتغير الدور؟ (ب) لو جعلنا **طول السلك** ٤ أمثال ما كان — ماذا يحدث للدور؟ (ج) هل يعمل نواس الفتل في المحطة الفضائية؟

## 📖 الفكرة

### ١. ما هو نواس الفتل ولماذا هو «نسخة دورانية» من النابض؟
ساق (أو قرص) متجانسة معلّقة **من مركزها** إلى سلك فولاذي شاقولي. نديرها في **المستوي الأفقي** زاوية `θ` ونتركها: ينفتل السلك ويولّد **مزدوجة فتل** تعيد الساق. الساق تهتز **دورانياً** حول محور السلك — لذا نصفها بالزوايا لا بالمسافات:

| النابض (الدرس ١) | نواس الفتل | |
|---|---|---|
| المطال `x` (m) | **المطال الزاوي** `θ` (rad) | |
| السعة `XmaX` | **السعة الزاوية** `θmax` | |
| السرعة `v = x′` | السرعة الزاوية `θ′` (rad·s⁻¹) | |
| التسارع `a = x″` | التسارع الزاوي `θ″` (rad·s⁻²) | |
| الكتلة `m` | **عزم العطالة** `IΔ` (kg·m²) | مقاومة الدوران |
| ثابت الصلابة `k` (N·m⁻¹) | **ثابت الفتل** `k` (N·m·rad⁻¹) | |
| قوة الإرجاع `F = −k·x` | **عزم الإرجاع** `Γ = −k·θ` | |
| `Ep = ½·k·x²` | `Ep = ½·k·θ²` | |
| `Ek = ½·m·v²` | `Ek = ½·IΔ·θ′²` | |

**[أستاذ] التعريف للامتحان:** نواس الفتل: جسم صلب متجانس (ساق أو قرص) معلّق من مركزه إلى سلك فتل شاقولي ثابت فتله `k`، يمكنه أن يهتز في مستوٍ أفقي حول محور السلك.

### ٢. لماذا لا يظهر الثقل ولا التوتر في المعادلة؟
القوى الخارجية على الساق: ثقلها `w`، توتر السلك `T`، وعزم مزدوجة الفتل `Γ`. نطبّق العلاقة الأساسية في التحريك الدوراني حول محور السلك `Δ`:
`ΣΓ/Δ = IΔ·θ″`
**عزم `w` وعزم `T` معدومان** لأن حامل كلٍّ منهما **منطبق على محور الدوران** (ذراعهما صفر). يبقى عزم مزدوجة الفتل وحده:
> `Γ = −k·θ` — **عزم الإرجاع**: يتناسب طرداً مع زاوية الفتل ويعاكسها بالإشارة.

`k` **ثابت فتل السلك** بوحدة N·m·rad⁻¹ (أو N·m). ⚠️ الرمز نفسه `k` للنابض وللسلك — لكنهما مقداران مختلفان بوحدتين مختلفتين.

### ٣. المعادلة التفاضلية والبرهان
`−k·θ = IΔ·θ″` ⇒ **`θ″ + (k/IΔ)·θ = 0`**

## 🧮 البرهان المُرقَّم (بنية الدرس ١ نفسها — تُقدّر ٢٥ إذا سُئل)

| # | الخطوة | درجة متوقعة | تنبيه |
|---|---|---|---|
| ① | معادلة تفاضلية من المرتبة الثانية تقبل حلاً جيبياً: `θ = θmax·cos(ω0·t + φ)` | ٥ | لا تُهمل `φ` (−١) |
| ② | `θ′ = −ω0·θmax·sin(ω0·t + φ)` (تابع السرعة الزاوية) | ٤ | |
| ③ | `θ″ = −ω0²·θmax·cos(ω0·t + φ)` (تابع التسارع الزاوي) | ٤ | |
| ④ | `θ″ = −ω0²·θ` | ٢ | الإشارة السالبة (−٤) |
| ⑤ | بالمطابقة: `ω0² = k/IΔ` | ٢ | |
| ⑥ | `ω0 = √(k/IΔ)` ممكن لأن `k` و`IΔ` موجبان ⇒ الحركة **جيبية دورانية** | ١+١ | كلمة «دورانية» مطلوبة |
| ⑦ | `2π/T0 = √(k/IΔ)` | ٢ | |
| ⑧ | **`T0 = 2π·√(IΔ/k)`** | ٤ | |

**دلالات الرموز (تُطلب دائماً مع «اذكر دلالات الرموز والواحدات»):** `T0` الدور الخاص (s) · `IΔ` عزم عطالة الجملة حول محور السلك (kg·m²) · `k` ثابت فتل السلك (N·m·rad⁻¹).

**برهان بديل يطلبه الكتاب (ص ٢٧ س٢):** من **مصونية الطاقة**: `E = ½·k·θ² + ½·IΔ·θ′² = const`. نشتق بالنسبة للزمن: `k·θ·θ′ + IΔ·θ′·θ″ = 0` ⇒ نقسم على `θ′ ≠ 0`: `θ″ + (k/IΔ)·θ = 0` ثم نكمل من ①.

## 📖 الفكرة (تابع)

### ٤. ماذا يعتمد عليه الدور؟ (التجارب الثلاث في الكتاب ص ٢٣–٢٤)
- تجربة ١: نغيّر السعة الزاوية ⇒ **الدور لا يتغير** (لا يتعلق بـ`θmax`).
- تجربة ٢: نثبّت كتلتين نقطيتين على الساق ⇒ **يزداد الدور** بزيادة عزم العطالة: `T0 ∝ √IΔ`.
- تجربة ٣: نجعل طول السلك نصفه ⇒ **ينقص الدور**؛ لأن ثابت الفتل يتعلق بطول السلك.

**[أستاذ + الكتاب ص ٢٥]** ثابت الفتل: `k = C·r⁴/l` (`C` ثابت المادة، `r` قطر/نصف قطر السلك، `l` طوله). **إذن `k ∝ 1/l`**، ومنه `T0 ∝ √l`.
> **[أستاذ] قاعدة النسبة عند تغيير طول السلك:** `T0′/T0 = √(l′/l)`.
> - طول السلك ٤ أمثال ⇒ `T0′ = 2·T0`.
> - طول السلك ربع ⇒ `T0′ = T0/2`.
> - نريد الدور مثلي ما كان ⇒ `l′ = 4·l`.
> - **[أستاذ] حالة الكتاب ص ٢٨:** نقسم السلك نصفين ونعلّق الساق بهما معاً (أعلى وأسفل): كل نصف ثابته `2k` ويعملان معاً ⇒ `k′ = 4k` ⇒ `T0′ = T0/2`.
> - **[أستاذ]** نحذف ربع السلك ونعلّق بالباقي: `l′ = ¾·l` ⇒ `T0′ = T0·√(3/4) = (√3/2)·T0`.

**جواب سؤال التوقّع:** (أ) قرص بالكتلة نفسها وقطر مضاعف ⇒ `IΔ = ½·m·r²` تصير ٤ أمثال ⇒ **`T0` يتضاعف**. (ب) `l′ = 4l` ⇒ `T0′ = 2T0`. (ج) **نعم** يعمل في الفضاء — الدور لا يحوي `g`؛ الإرجاع من مرونة السلك لا من الجاذبية. **[أستاذ: «أي ميقاتية مرن أو فتل لا تتعلق بالارتفاع»]**

> **⚠️ الخطأ الشائع ١:** «زيادة كتلة القرص تزيد الدور» — صحيح **فقط** إذا حافظنا على القطر (لأن `IΔ ∝ m`). زيادة **القطر** أشد أثراً لأن `IΔ ∝ r²`. (الكتاب ص ٢٦ MCQ الميقاتية: لتصحيح **تأخير** ميقاتية الفتل نُنقص الدور ⇒ **إنقاص طول السلك** بمقدار ضئيل — الخيار c.)

### ٥. عزم العطالة: كيف أحسبه في المسائل؟ **[أستاذ — طرق الحل ٢]**
`IΔ` للجملة = مجموع عزوم أجزائها حول محور السلك:
- ساق متجانسة طولها `l` كتلتها `m` معلّقة من منتصفها: `(1/12)·m·l²`
- قرص متجانس نصف قطره `r`: `½·m·r²`
- كتلة نقطية `m1` على بعد `r1`: `m1·r1²`
- **جملة (ساق + كتلتين نقطيتين على طرفيها):** `IΔ = (1/12)·m·l² + 2·m1·(l/2)²`
- ساق **مهملة الكتلة** + كتلتان: `IΔ = 2·m1·(l/2)² = ½·m1·l²`

**طرق أخرى لإيجاد `IΔ` [أستاذ]:** من `T0 = 2π√(IΔ/k)` إذا عُرف `k` و`T0`؛ أو من `Γ = IΔ·θ″` إذا عُرف عزم وتسارع زاوي.

### ٦. التوابع والطاقة والمواضع الحدية
| المقدار | أعظمي في | معدوم في |
|---|---|---|
| `θ` | الطرفين `±θmax` | مركز الاهتزاز |
| `θ′` (عظمى `ω0·θmax`) | مركز الاهتزاز | الطرفين |
| `θ″ = −ω0²·θ` (عظمى `ω0²·θmax`) | الطرفين | المركز |
| `Γ = −k·θ` (عظمى `k·θmax`) | الطرفين | المركز |
| `Ep = ½·k·θ²` | الطرفين (= `E`) | المركز |
| `Ek = ½·IΔ·θ′²` | المركز (= `E`) | الطرفين |

`E = ½·k·θmax² = const` · السرعة الزاوية في مطال معلوم: `θ′ = ±ω0·√(θmax² − θ²)`.

**[أستاذ] إشارة السرعة الزاوية عند المرور بالمركز:** إذا انطلق من مطال **موجب** فالمرورات **الفردية** (الأول، الثالث…) سالبة والزوجية موجبة؛ إذا انطلق من مطال سالب فالعكس. **لماذا؟** لأنه في المرور الأول يتجه من الطرف الموجب نحو السالب.

**[أستاذ] أزمنة المرور بالمركز** عند الانطلاق من الطرف دون سرعة ابتدائية (`φ = 0`): `T0/4، 3T0/4، 5T0/4…` — أعداد فردية من `T0/4`.

## ✍️ مثال محلول ١ (الكتاب ص ٢٧ المسألة الثانية — بنمط السلم)
**المسألة:** ساق مهملة الكتلة طولها `l`، في طرفيها كتلتان نقطيتان `m1 = 125 g` لكل منهما، معلّقة من منتصفها بسلك ثابت فتله `k = 0.4 N·m·rad⁻¹` (قيمة مفترضة — الرقم غير مقروء في النسخة؛ **يُراجع مع الأستاذ**). نديرها `θmax = 0.3 rad` ونتركها دون سرعة ابتدائية عند `t = 0`. دورها `T0 = 2.5 s`. `π² = 10`.
**المطلوب:** (١) التابع الزمني للمطال الزاوي من شكله العام. (٢) السرعة الزاوية لحظة المرور الأول بالتوازن. (٣) طول الساق.

**المبدأ الحاكم:** «تُركت دون سرعة ابتدائية من الزاوية `θmax`» ⇒ `φ = 0` **[أستاذ: «لأنه ترك دون سرعة ابتدائية»]**.

| الخطوة | الكتابة | درجة |
|---|---|---|
| (١) الشكل العام | `θ = θmax·cos(ω0·t + φ)` | ٥ |
| `ω0` | `ω0 = 2π/T0 = 2π/2.5 = 0.8π rad·s⁻¹` | ٣+١ |
| `φ` من شروط البدء | `t = 0: θ = θmax ⇒ cos φ = 1 ⇒ φ = 0` (تُركت دون سرعة ابتدائية) | ٣ |
| التابع | `θ = 0.3·cos(0.8π·t)` | ٢ |
| (٢) العلاقة | `θ′ = −ω0·θmax·sin(ω0·t)`؛ عند المرور الأول بالمركز `t = T0/4` ⇒ `sin = 1` | ٥ |
| النتيجة | `θ′ = −0.8π×0.3 = −0.24π ≈ −0.75 rad·s⁻¹` (**سالبة**: انطلق من مطال موجب) | ٣+١+١ |
| (٣) العلاقة | `T0 = 2π√(IΔ/k)` مع `IΔ = 2·m1·(l/2)² = ½·m1·l²` | ٥+٣ |
| عزل `l` | `T0² = 4π²·m1·l²/(2k) ⇒ l = T0·√(2k/(4π²·m1)) = T0·√(k/(2π²·m1))` | ٣ |
| النتيجة | `l = 2.5·√(0.4/(2×10×0.125)) = 2.5·√0.16 = 2.5×0.4 = 1 m` | ٣+١+١ |

## ✍️ مثال ٢ — أكمل الخطوات (الكتاب ص ٢٧ المسألة الأولى)
قرص متجانس `m = 2 kg`، `r = 0.2 m` (مفترض)، `k = 0.4 N·m·rad⁻¹` (مفترض)، يُدار `θmax = 0.4 rad` ويُترك عند `t = 0`. `π² = 10`.
(١) `IΔ = ½·m·r² = ½×2×0.04 = ▢ kg·m²` ⇒ `T0 = 2π√(IΔ/k) = 2π√(0.04/0.4) = 2π×▢ ≈ 2 s`.
(٢) `φ = ▢` (تُرك دون سرعة ابتدائية) ⇒ `θ = 0.4·cos(π·t)`.
(٣) عند `θ = 0.2 rad`: `Ep = ½·k·θ² = ½×0.4×0.04 = ▢ J`؛ `E = ½·k·θmax² = ½×0.4×0.16 = ▢ J` ⇒ `Ek = E − Ep = ▢ J`.

## ⚖️ خصومات السلم
1. إغفال «دورانية» في النتيجة («جيبية» وحدها ناقصة).
2. إغفال تبرير `φ = 0` («لأنه تُرك دون سرعة ابتدائية»).
3. سرعة زاوية عند المرور بلا إشارة.
4. إغفال `φ` في الحل المقترح −١، إغفال الإشارة السالبة −٤.
