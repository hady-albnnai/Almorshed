## 📖 الفكرة

### ١. ما هو التيار المتناوب وكيف ينشأ إلكترونياً؟ [أستاذ س١–س٢]
- **المستمر DC:** حركة إلكترونات إجمالية باتجاه واحد من الكمون المنخفض إلى المرتفع بتأثير حقل كهربائي **ثابت** ناتج عن التوتر المطبق (مصدره البطارية).
- **المتناوب AC:** تتغير شدته وجهته دورياً؛ أشكاله: جيبي، منشاري، مثلثي، رباعي (مصدره تيار المدينة). **الجيبي إلكترونياً:** حركة **اهتزازية** للإلكترونات الحرة حول مواضع وسطية **بسعة صغيرة جداً (رتبة μm)** وبتواتر التيار، تنشأ عن حقل كهربائي متغير القيمة والجهة **ينتشر بجوار الناقل بسرعة الضوء**، ناتج عن التوتر المتغير المطبق.

**شرطا تطبيق قوانين أوم (للمستمر) على دارة متناوبة في كل لحظة:** ① الدارة **قصيرة** بالنسبة لطول الموجة `λ = c/f` (لتيار المدينة `f = 50 Hz` ⇒ `λ = 6000 km`) ② تواتر التيار **صغير**. **لماذا؟** لأن الإلكترونات في دارة قصيرة تهتز بتوافق كامل فتبدو مقاطع الدارة في كل لحظة كأن تياراً متواصلاً يجتازها شدته الشدة اللحظية. **[أستاذ: أولاً ص ١٥٦]**
**الاهتزازات القسرية:** تهتز الإلكترونات بالنبض الذي **يفرضه المولد** لا بنبضها الخاص ⇒ المولد جملة محرِّضة والدارة جملة متجاوبة.

### ٢. المصطلحات والقيم المنتجة [أستاذ]
`i = Imax·cos(ωt + φ1)` · `u = Umax·cos(ωt + φ2)` · **`φ = φ2 − φ1` فرق الطور بين التوتر والتيار** (يتغير بمكونات الدارة).
**لماذا القيم المنتجة؟** كل تيار متناوب يكافئ حرارياً تياراً متواصلاً لأن الاستطاعة الحرارية `Ri²` لا تتعلق بالجهة.
- **الشدة المنتجة (الفعالة) `Ieff`:** شدة تيار متواصل يعطي **كمية الطاقة الحرارية نفسها** التي يعطيها المتناوب في الناقل الأومي نفسه خلال الزمن نفسه. **`Ieff = Imax/√2`**.
- **التوتر المنتج `Ueff`:** بالمثل. **`Ueff = Umax/√2`**. (تيار المدينة `220 V` منتج ⇒ `Umax = 220√2 ≈ 311 V`.)
- **قراءة مسألة ٢٠٢٦:** `u = 120√2·cos(120πt)` ⇒ `Ueff = 120 V`، `ω = 120π` ⇒ `f = 60 Hz`.

### ٣. الاستطاعات [أستاذ]
- **اللحظية:** `p = u·i` — تتغير من لحظة لأخرى.
- **المتوسطة المستهلكة:** معدل الطاقة المقدمة للدارة: **`P = Ueff·Ieff·cos φ`** (W). وتُصرف **حرارياً في المقاومة فقط**: **`P = R·Ieff²`**.
- **الظاهرية:** `S = Ueff·Ieff` (VA) — أكبر قيمة ممكنة للمتوسطة.
- **عامل الاستطاعة:** `cos φ = P/S` (بلا وحدة). **كلما زاد `cos φ` نقصت الاستطاعة الضائعة** في خطوط النقل (لتقديم `P` نفسها بـ`Ieff` أصغر). **[أستاذ: ثانياً ص ١٥٦]**

### ٤. العناصر الثلاثة على حدة — الجدول الذهبي [أستاذ س٣–س٥ / الكتاب ص ١٤٦–١٥٠]
نطبق `i = Imax·cos(ωt)` (محور الطور = محور التيار في التسلسل).

| | مقاومة أومية `R` | ذاتية صرف `L` (وشيعة مهملة المقاومة) | مكثفة `C` |
|---|---|---|---|
| **اشتقاق `u`** | `u = R·i = R·Imax·cos(ωt)` | `u = L·di/dt = −LωImax·sin(ωt) = LωImax·cos(ωt + π/2)` | `q = ∫i dt = (Imax/ω)·sin(ωt)` ⇒ `u = q/C = (Imax/Cω)·cos(ωt − π/2)` |
| **الممانعة** | `R` (Ω) | **`XL = Lω`** «ردّية الوشيعة» (Ω) | **`XC = 1/(Cω)`** «اتساعية المكثفة» (Ω) |
| **القيم المنتجة (أوم)** | `Ueff = R·Ieff` | `Ueff = Lω·Ieff` | `Ueff = Ieff/(Cω)` |
| **الطور** | `φ = 0` — **توافق بالطور** | `φ = +π/2` — التوتر **متقدم** على التيار بربع دور (ترابع متقدم) | `φ = −π/2` — التوتر **متأخر** عن التيار بربع دور (ترابع متأخر) |
| **فرينل** | `U⃗R` على محور `I⃗` | `U⃗L` عمودي للأعلى | `U⃗C` عمودي للأسفل |
| **الاستطاعة المتوسطة** | `P = UI cos 0 = R·Ieff²` — تُصرف حرارياً بجول | `P = UI cos(π/2) = 0` — **لا تستهلك**: تختزن كهرطيسياً ربع دور وتعيدها كهربائياً في الربع التالي | `P = 0` — **لا تستهلك**: تختزن كهربائياً ربع دور وتعيدها في التالي |
| **مع DC** | نفسه | الوشيعة الحقيقية `(r, L)`: مقاومة أومية فقط `r` | **لا تمرر** المستمر (العازل بين لبوسيها) |

**جواب سؤال التوقّع:** (أ) نواة ⇒ `L↑` ⇒ `XL↑` ⇒ `Z↑` ⇒ `Ieff↓` ⇒ **تنقص** الإضاءة **[أستاذ: أولاً ص ١٥٦]**. (ب) `f↑` ⇒ `XC = 1/(2πfC)↓` ⇒ **تزداد**. (ج) لا.

**لماذا تمرر المكثفة المتناوب وتعرقله؟ [أستاذ ص ١٥٦/٤]** الإلكترونات المهتزة تشحن اللبوسين خلال ربع دور بشحنتين متساويتين مختلفتي النوع **دون أن تخترق العازل**، ثم يتفرغان في الربع التالي، وفي النوبة الثانية تتكرر العمليتان بالإشارة المعاكسة ⇒ يمر تيار في الدارة الخارجية؛ لكن **الحقل الكهربائي** الناتج عن شحنتها يعرقل المرور.

> **⚠️ الخطأ الشائع ١:** «الوشيعة والمكثفة تستهلكان طاقة لأن لهما ممانعة». الممانعة تحدّ التيار لكن `cos φ = 0` ⇒ `P = 0`. **الطاقة تُصرف في `R` فقط** — لذا `P = R·Ieff²` دائماً، حتى في `R–L–C`.

### ٥. الوصل على التسلسل — القواعد الخمس [أستاذ ملاحظات التسلسل]
1. عناصر الدارة ثلاثة على الأكثر (`R`، `L`، `C`)؛ أكثر من واحد من نوع ⇒ مكافئ. **الوشيعة الحقيقية = `r` + `L` على التسلسل**.
2. **الشدة واحدة** لجميع العناصر ⇒ **محور الطور هو محور التيار**؛ `i = Imax·cos(ωt)`، `u = Umax·cos(ωt + φ)`.
3. توتر المنبع = **مجموع** التوترات: كتوابع جيبية `u = uR + uL + uC` (جمع جبري لحظي)، وكأشعة فرينل `U⃗ = U⃗R + U⃗L + U⃗C` (جمع هندسي للمنتجة).
4. قانون أوم: **`Ueff = Z·Ieff`**.
5. **إنشاء فرينل** (حصراً في التسلسل لتمثيل الممانعات): `Z² = R² + (XL − XC)²`.

**الدارات المتسلسلة الخمس:**
| الدارة | `Z` | `tan φ` | `cos φ` | الطور |
|---|---|---|---|---|
| `R–L` (أو وشيعة `r, L`) | `√(R² + L²ω²)` | `Lω/R` | `R/Z` | التوتر **متقدم** (`0 < φ < π/2`) |
| `R–C` | `√(R² + 1/C²ω²)` | `−1/(RCω)` | `R/Z` | التوتر **متأخر** |
| `R–L–C` | **`√(R² + (Lω − 1/Cω)²)`** | `(Lω − 1/Cω)/R` | `R/Z` | ثلاث حالات ↓ |

**الحالات الثلاث لـ`R–L–C` تسلسل:**
- `Lω > 1/Cω` (ردية > اتساعية): الدارة **ذات ممانعة ذاتية مكافئة**؛ التوتر متقدم بالطور على التيار.
- `Lω < 1/Cω`: **ممانعة سعوية مكافئة**؛ التوتر متأخر.
- `Lω = 1/Cω`: **الطنين (التجاوب الكهربائي)**؛ التوتر على توافق بالطور مع التيار.

### ٦. الطنين — التجاوب الكهربائي [أستاذ س٦ / الكتاب ص ١٥٢]
**الشرط:** النبض القسري للمولد = النبض الخاص للدارة: `ω = ω0 = 1/√(LC)` ⇒ `Lω = 1/(Cω)` ⇒ **`LCω² = 1`** ⇒ **`T = 2π√(LC)`**، `f = 1/(2π√(LC))` (طومسون من جديد).
**يتحقق في الطنين (كلها دلائل مقبولة كجواب «بيّن أن الدارة في حالة طنين»):**
1. `XL = XC` (الردية = الاتساعية).
2. `φ = 0` — التوتر على توافق بالطور مع التيار.
3. `cos φ = 1` — عامل الاستطاعة أكبر ما يمكن.
4. **`Z = R` أصغر ما يمكن**.
5. **`Ieff = Ueff/R` أكبر ما يمكن**.
6. `P = Ueff·Ieff` أكبر ما يمكن (= الظاهرية).
7. `UR = U` (توتر المقاومة = توتر المنبع)؛ `UL = UC` (يتعاكسان ويلغيان بعضهما — وقد يكون كل منهما **أكبر** من توتر المنبع!).
**[أستاذ — هامة]:** عندما يُطلب `P` في الطنين: نحسب أولاً `Ieff` **الجديدة** `= Ueff/R` ثم `P = R·Ieff²`.

> **⚠️ الخطأ الشائع ٢:** «في الطنين `UL = 0` و`UC = 0`». لا — كل منهما قد يكون كبيراً؛ **مجموعهما الشعاعي** صفر فقط.

### ٧. الوصل على التفرع [أستاذ ملاحظات التفرع / الكتاب ص ١٥٤]
1. **لا تُطبق قوانين أوم على الدارة ككل** بل على كل فرع وحده باعتباره دارة متسلسلة.
2. **التوتر واحد** لجميع الأفرع ⇒ **محور الطور هو محور التوتر**؛ `u = Umax·cos(ωt)`.
3. شدة المنبع = **مجموع** شدات الأفرع: جبرياً كتوابع `i = i1 + i2 + …`، هندسياً كأشعة فرينل.
4. الأطوار بالنسبة للتوتر: فرع `R`: `I⃗R` على محور `U⃗` · فرع `L`: التيار **متأخر** `π/2` · فرع `C`: التيار **متقدم** `π/2`.

**الدارة الفرعية `R ∥ L ∥ C`:** `IR = U/R`، `IL = U/(Lω)`، `IC = UCω` ⇒ `I² = IR² + (IC − IL)²`، `tan φ = (IC − IL)/IR`.
**`L ∥ C` — الدارة الخانقة [أستاذ س٧]:** عندما `Lω = 1/Cω` يكون `IL = IC` ومتعاكسان ⇒ **تنعدم شدة التيار في الدارة الخارجية** — **خنق التيار**، بالشرط نفسه `LCω² = 1` و`T = 2π√(LC)`. (طنين ⇔ `R–L–C` **تسلسل**؛ خنق ⇔ `L–C` **تفرع**.)

### ٨. طرق الحل [أستاذ طرق حل ١–٧]
1. **أوم:** عنصر وحيد `U = X·I`؛ أكثر من عنصر `U = Z·I`.
2. **`P = UI cos φ = R·I²`** (تسلسل) — والثانية تسمح باستخراج `R` أو `I`.
3. **`cos φ = P/(UI) = R/Z`** (الثانية حصراً تسلسل أو فرع وحيد).
4. **إنشاء فرينل:** مثلث قائم (تسلسل) أو غير قائم (فرعان بأكثر من عنصر) — نحلّه بفيثاغورث أو قانون الجيب/التجيب.
5. **التوابع الزمنية:** تسلسل `i = I√2·cos(ωt)`، `u = U√2·cos(ωt + φ)`؛ تفرع `u = U√2·cos(ωt)`، `i = I√2·cos(ωt − φ)`.
6. **الطنين:** حصراً `R–L–C` تسلسل بإحدى الدلائل السبع.
7. **إضافة عنصر على التسلسل مع بقاء `Ieff` ثابتة:** `Z′ = Z` ⇒ `(Lω − 1/Cω)′² = (Lω − 1/Cω)²` ⇒ إما `X′ = X` أو `X′ = −X` ⇒ حلان للعنصر المضاف.
8. **تحويل وشيعة `(r, L)` مجهولة:** بـDC: `r = U/I`؛ بـAC: `Z = U/I` ⇒ `Lω = √(Z² − r²)`. **[أستاذ مسألة ٢ ص ١٥٧]**

## 🧾 خلاصة
| | |
|---|---|
| `Ieff = Imax/√2`، `Ueff = Umax/√2` | تكافؤ حراري |
| `XL = Lω`، `XC = 1/Cω`، `Z = √(R² + (XL − XC)²)` | تسلسل |
| `Ueff = Z·Ieff` · `cos φ = R/Z` · `tan φ = (XL − XC)/R` | |
| **`P = UI cos φ = R·I²`** | في `R` فقط |
| L: التوتر متقدم `π/2`؛ C: متأخر `π/2`؛ R: توافق | فرينل |
| طنين: `LCω² = 1` ⇒ `Z = R`، `I` أعظمي، `cos φ = 1`، `UL = UC` | تسلسل |
| خنق: `LCω² = 1` ⇒ `I = 0` خارجياً | `L ∥ C` |
| تفرع: `I² = IR² + (IC − IL)²` | محور الطور = `U` |
| وشيعة مجهولة: DC ⇒ `r`؛ AC ⇒ `Z` ⇒ `Lω = √(Z² − r²)` | |

## ⚖️ خصومات السلم (٢٠٢٦ مسألة ٣)
1. `Ueff` مقروءة `120√2` بدل `120` (يُتلف كل ما بعده).
2. فرينل بلا محور طور صحيح (التيار في التسلسل) أو بلا تسمية الأشعة.
3. `P = UI` بلا `cos φ` (−٥).
4. `cos φ = R/Z` في **تفرع** (خطأ مبدئي).
5. وحدات Ω / W / H / F.
6. إشارة `φ` في تابع التيار (`−φ` إذا كان التيار متأخراً).
