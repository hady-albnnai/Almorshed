# الوحدة ٢ · الدرس ٤: الدارات المهتزة — التفريغ المهتز، علاقة طومسون، الطاقة الكلية

> **سؤال إجباري في ٢٠٢٦: س٤ = ٣٠ درجة (إثبات ثبات الطاقة الكلية).** المصادر: الكتاب ص ١٢٦–١٣٧ · الأستاذ فداء «الكهرباء» (دارة الاهتزاز س١–س٦ + طرق الحل + مسائل ص ١٣٦–١٣٧). الرموز: `q` الشحنة (C)، `Qmax`، `C` السعة (F)، `L` الذاتية (H)، `r`/`R` مقاومة، `i = dq/dt`، `ω0`، `T0`، `f0`، `EC = q²/2C` الطاقة الكهربائية، `EL = ½Li²` الكهرطيسية، `E` الكلية.
> حالة: **مسوّدة** · `approved:false`.

---

## 🔑 قبل أن تبدأ
**تحتاج:** `uC = q/C`، `EC = ½·q²/C = ½CU²`، `EL = ½Li²` (L3)، `uL = L·di/dt` (توتر الوشيعة عند إهمال `r`)، بنية برهان «حركة جيبية» من U1/L1 (الحل نفسه للمرة الثالثة!)، المشتق `d(cos)/dt`.

**سؤال توقّع:**
> مكثفة مشحونة نصلها بوشيعة. (أ) هل تتفرغ مرة واحدة كما تتفرغ عبر مقاومة؟ (ب) لو ضاعفنا `C` و`L` معاً — ماذا يحدث للدور؟ (ج) عند اللحظة التي يكون فيها التيار أعظمياً، كم شحنة المكثفة؟

## 📖 الفكرة

### ١. الدارة والتجربة (الكتاب ص ١٢٨) [أستاذ س١]
مولد `E`، مكثفة `C`، وشيعة `(L, r)`، قاطعة دوّارة، راسم اهتزاز على لبوسي المكثفة.
- **الوضع ١:** تُشحن المكثفة من المولد ⇒ تختزن طاقة كهربائية `½CE²`.
- **الوضع ٢:** تتفرغ شحنة المكثفة **عبر الوشيعة**؛ نميز **ثلاثة أشكال للتفريغ** حسب المقاومة الأومية:

| المقاومة | نوع التفريغ | الشكل على الراسم | الاسم |
|---|---|---|---|
| **مهملة** (حالة مثالية) | دوري متناوب **جيبي غير متخامد**؛ السعة ثابتة | جيبية تامة | دارة `L–C` **حرة غير متخامدة** |
| **صغيرة** | دوري متناوب (باتجاهين) **متخامد**؛ السعة تتناقص حتى تنعدم؛ زمن التفريغ ثابت يسمى **شبه الدور** | جيبية تتناقص سعتها | دارة `R–L–C` **حرة متخامدة** |
| **كبيرة جداً** | **لا دوري** غير متناوب (باتجاه واحد)؛ السعة تتناقص دفعة واحدة وتنعدم | منحنٍ يهبط دون تذبذب | تفريغ لا دوري |

**لماذا «حرة»؟** لأنها لا تتلقى طاقة من المولد بعد الفصل. **لماذا تتخامد؟** لأن طاقة المكثفة تضيع **حرارياً في المقاومة بفعل جول** (جواب سؤال التوقّع أ: مع وشيعة تتفرغ ذهاباً وإياباً، لا مرة واحدة).
**[أستاذ] `R–C` و`R–L` ليستا دارتين مهتزتين:** `R–C` لأن طاقة المكثفة تضيع حرارياً ولا توجد ذاتية `L` **لإعادة شحن** المكثفة؛ `R–L` لأن لا مكثفة تختزن الشحنة أصلاً.

### ٢. الدراسة التحليلية — المعادلة التفاضلية [أستاذ س٢ / الكتاب ص ١٢٩]
دارة تسلسل: وشيعة `(r, L)`، مكثفة `C`، مقاومة `R`؛ أسلاك التوصيل مهملة المقاومة.
- توتر الوشيعة: `uL = r·i + L·di/dt`
- توتر المقاومة: `uR = R·i`
- توتر المكثفة: `uC = q/C`
- مجموع التوترات في الدارة المغلقة (بلا مولد) = ٠: `L·di/dt + (R + r)·i + q/C = 0`
- مع `i = dq/dt` و`di/dt = d²q/dt² = q″`:
> **`L·q″ + (R + r)·q′ + q/C = 0`** — معادلة تفاضلية من المرتبة الثانية تصف اهتزاز الشحنة في `R–L–C` (الحد الأوسط هو حد التخامد).

**حالة خاصة `R + r = 0`:** **`q″ + (1/LC)·q = 0`** — معادلة `L–C` غير المتخامدة.

## 🧮 البرهان المُرقَّم ١ — علاقة طومسون (نمط س٣ ٢٥) [أستاذ س٣ / الكتاب ص ١٣٠]
| # | | درجة |
|---|---|---|
| ① | `q″ + (1/LC)·q = 0` معادلة تفاضلية من المرتبة الثانية تقبل حلاً جيبياً: `q = Qmax·cos(ω0·t + φ)` | ٥ (φ −١) |
| ② | `q′ = −ω0·Qmax·sin(ω0 t + φ)` | ٤ |
| ③ | `q″ = −ω0²·Qmax·cos(ω0 t + φ) = −ω0²·q` | ٤ (الإشارة −٤) |
| ④ | بالمطابقة: `ω0² = 1/LC` ⇒ `ω0 = 1/√(LC)` (ممكن لأن `L`، `C` موجبان) | ٤ |
| ⑤ | `ω0 = 2π/T0` ⇒ `2π/T0 = 1/√(LC)` | ٣ |
| ⑥ | **`T0 = 2π·√(LC)`** — **علاقة طومسون** | ٣ |
| ⑦ | الدلالات: `T0` الدور الخاص للاهتزازات الكهربائية الحرة غير المتخامدة (s) · `L` (H) · `C` (F) | ٢ |

`f0 = 1/T0 = 1/(2π√(LC))` التواتر الخاص. **جواب سؤال التوقّع (ب):** `LC` يصير ٤ أمثال ⇒ `T0` **يتضاعف**.

> **⚠️ الخطأ الشائع ١:** تقابل `q ↔ x`، `L ↔ m`، `1/C ↔ k`. أي `T0 = 2π√(m/k) ↔ 2π√(L·C)` — السعة في **البسط** تحت الجذر (لأن `1/C` هي «الصلابة»). طلاب كثر يكتبون `√(L/C)`.

### ٣. توابع الشحنة والتيار [أستاذ س٤ / الكتاب ص ١٣٠]
**الشكل العام:** `q = Qmax·cos(ω0·t + φ)` — `q` الشحنة اللحظية (C)، `Qmax` العظمى (C)، `ω0` النبض الخاص (rad·s⁻¹)، `φ` الطور الابتدائي (rad)، `(ω0 t + φ)` طور الحركة.
**مبدأ الزمن لحظة إغلاق الدارة (المكثفة مشحونة كلياً):** `t = 0 ⇒ q = Qmax ⇒ cos φ = 1 ⇒ φ = 0` ⇒
> `q = Qmax·cos(ω0 t)` · `i = dq/dt = −ω0·Qmax·sin(ω0 t)` ⇒ **`Imax = ω0·Qmax = Qmax/√(LC)`**
ويمكن كتابة `i = Imax·cos(ω0 t + π/2)`: **تابع الشدة متقدم بالطور على تابع الشحنة بربع دور (`π/2`)** — «ترابع متقدم».
**المنحنيان:** عندما `q` عظمى يكون `i` معدوماً والعكس (جواب سؤال التوقّع ج: **صفر**). **حساب `Qmax`:** `Qmax = C·Umax = C·E` (شحنت من مولد `E`).

### ٤. تبادل الطاقة بين المكثفة والوشيعة خلال دور [أستاذ س٥ / الكتاب ص ١٣٢]
- **الربع الأول:** تتناقص شحنة المكثفة تدريجياً حتى تنعدم؛ يزداد تيار الوشيعة حتى أعظمي في نهايته ⇒ الوشيعة تختزن **طاقة كهرطيسية عظمى `½LImax²`**.
- **الربع الثاني:** يتناقص تيار الوشيعة حتى ينعدم؛ تزداد شحنة المكثفة حتى عظمى (بالإشارة المعاكسة) ⇒ المكثفة تختزن **طاقة كهربائية عظمى `Qmax²/2C`**.
- **النصف الثاني:** تتكرر عمليتا التفريغ والشحن **بالاتجاه المعاكس** نظراً لتغير شحنة اللبوسين.
⇒ تفريغ (ربع) → شحن (ربع) → تفريغ → شحن: **تتبادل الطاقة بين الكهربائية في المكثفة والكهرطيسية في الوشيعة** ومجموعهما ثابت.

## 🧮 البرهان المُرقَّم ٢ — الطاقة الكلية ثابتة (**س٤ ٢٠٢٦ = ٣٠ درجة**) [أستاذ س٦ / الكتاب ص ١٣٣]
| # | الخطوة | درجة |
|---|---|---|
| ① | الطاقة الكلية = كهربائية في المكثفة + كهرطيسية في الوشيعة: `E = q²/2C + ½·L·i²` | ٥ |
| ② | نعوّض `q = Qmax·cos(ω0 t)`: `EC = (Qmax²/2C)·cos²(ω0 t)` | ٤ |
| ③ | نعوّض `i = −ω0·Qmax·sin(ω0 t)`: `EL = ½·L·ω0²·Qmax²·sin²(ω0 t)` | ٤ |
| ④ | لكن `ω0² = 1/LC` ⇒ `L·ω0² = 1/C` ⇒ `EL = (Qmax²/2C)·sin²(ω0 t)` | ٥ |
| ⑤ | نجمع: `E = (Qmax²/2C)·[cos²(ω0 t) + sin²(ω0 t)]` | ٣ |
| ⑥ | `cos² + sin² = 1` ⇒ **`E = Qmax²/2C = ½·L·Imax² = const`** | ٥ |
| ⑦ | الاستنتاج: الطاقة الكلية ثابتة **لأن لا مقاومة** تبددها حرارياً؛ تتبادل بين المكثفة والوشيعة | ٤ |

**طريقة بديلة (تُقبل):** نشتق `E` بالنسبة للزمن: `dE/dt = (q/C)·q′ + L·i·i′ = i·(q/C + L·q″) = i·(q/C − q/C) = 0` باستخدام المعادلة التفاضلية ⇒ `E` ثابتة.

> **⚠️ الخطأ الشائع ٢ (يُسقط ٥–٩ درجات من الـ٣٠):** كتابة `EL = ½Li²` ثم التعويض بـ`i` دون استبدال `L·ω0² = 1/C` — يبقى الطالب عالقاً بحدَّين مختلفي المعامل ولا يستطيع الجمع. الخطوة ④ هي مفتاح البرهان.

### ٥. التيارات عالية التواتر (الكتاب ص ١٣٤)
مكثفة `C` من رتبة `pF–nF` مع وشيعة `L` من رتبة `μH–mH` ⇒ `T0 = 2π√(LC)` من رتبة `μs` ⇒ `f0` من رتبة `MHz` ⇒ **تيار عالي التواتر** (أساس الراديو والاتصالات).

## ✍️ مثال محلول ١ — مسألة نموذجية (بنية مسائل الكتاب ص ١٣٦–١٣٧) [أستاذ طرق الحل]
مكثفة `C = 10 μF` شُحنت بمولد `E = 20 V` ثم وُصلت عند `t = 0` بوشيعة `L = 0.1 H` مهملة المقاومة. `π² = 10`.
| | | |
|---|---|---|
| (١) `Qmax` | `Qmax = C·E = 10⁻⁵×20 = 2×10⁻⁴ C` | ٥+٣+١+١ |
| (٢) `T0` | `T0 = 2π√(LC) = 2π√(10⁻⁶) = 2π×10⁻³ ≈ 6.28×10⁻³ s` | ٥+٣+١+١ |
| `f0`، `ω0` | `f0 = 1/T0 ≈ 159 Hz` · `ω0 = 1/√(LC) = 10³ rad·s⁻¹` | ٣+١ |
| (٣) تابع الشحنة | `φ = 0` (المكثفة مشحونة كلياً عند `t = 0`) ⇒ `q = 2×10⁻⁴·cos(10³·t)` | ٥+٣ |
| (٤) تابع الشدة | `i = −ω0 Qmax sin(ω0 t) = −0.2·sin(10³·t)` ⇒ `Imax = 0.2 A` | ٥+٣+١+١ |
| (٥) الطاقة الكلية | `E = Qmax²/2C = (4×10⁻⁸)/(2×10⁻⁵) = 2×10⁻³ J`؛ تحقق `½LImax² = ½×0.1×0.04 = 2×10⁻³ J` ✓ | ٥+٣+١+١ |
| (٦) `i` عندما `q = Qmax/2` | `E = q²/2C + ½Li²` ⇒ `½Li² = E − E/4 = 1.5×10⁻³` ⇒ `i = √(3×10⁻²) ≈ 0.17 A` | ٥+٣+١+١ |
| (٧) الشكل مع مقاومة كبيرة جداً **[أستاذ]** | تفريغ لا دوري، السعة تنعدم دفعة واحدة — لأن الطاقة تضيع حرارياً بجول | ٥ |

**قاعدة [أستاذ طرق حل]:** «بدء الزمن لحظة إغلاق الدارة/وصل المكثفة المشحونة بالوشيعة» ⇒ `φ = 0` دائماً. المجهول من طومسون بعزله: `L = T0²/(4π²C)` أو `C = T0²/(4π²L)`.

## ✍️ مثال ٢ — أكمل: من الخط البياني
منحني `q(t)` يقطع محور الزمن أول مرة عند `t = 0.5 ms` وذروته `4×10⁻⁶ C`. `L = 2 mH`.
- `T0/4 = 0.5 ms ⇒ T0 = ▢ ms` ⇒ `C = T0²/(4π²L) = ▢ F`.
- `Imax = ω0·Qmax = (2π/T0)·4×10⁻⁶ = ▢ A`.
- `E = ▢ J`.

## 🎯 اختبر نفسك
**س١.** دارة `L–C`؛ نجعل `C` أربعة أمثال: (A) `T0` ٤ أمثال · **(B) `T0` مثلان** ✓ · (C) `T0` نصف · (D) لا يتغير.
**س٢.** في دارة `L–C` عندما تكون شحنة المكثفة عظمى: **(A) `i = 0` و`EL = 0`** ✓ · (B) `i` عظمي · (C) `EC = 0` · (D) الطاقة الكلية عظمى ⟵ *الكلية ثابتة دائماً*.
**س٣.** دارة `R–C` ليست مهتزة لأن: (A) `R` كبيرة · **(B) لا ذاتية لإعادة شحن المكثفة** ✓ · (C) المكثفة لا تختزن · (D) التيار مستمر.
**س٤.** تابع الشدة بالنسبة لتابع الشحنة: **(A) متقدم بـ`π/2`** ✓ · (B) متأخر بـ`π/2` · (C) على توافق · (D) متعاكس.
**س٥.** لماذا تتخامد الاهتزازات مع مقاومة صغيرة؟ > تضيع طاقة المكثفة تدريجياً حرارياً بجول في `R`.
**س٦.** ماذا نسمي زمن التفريغ في الحالة المتخامدة ولماذا لا نسميه دوراً؟ > **شبه الدور** — لأن السعة متناقصة فالحركة ليست دورية بالمعنى الدقيق.
**س٧.** اكتب مقابلات النواس المرن ↔ الدارة المهتزة. > `x↔q`، `v↔i`، `m↔L`، `k↔1/C`، `½kx²↔q²/2C`، `½mv²↔½Li²`.

## ⚖️ خصومات السلم
1. `φ` مهملة −١، الإشارة السالبة في `q″ = −ω0²q` −٤.
