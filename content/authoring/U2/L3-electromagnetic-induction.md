## 📖 الفكرة

### ١. التجربة الأساسية: مغناطيس ووشيعة [أستاذ س١]
وشيعة طرفاها بمقياس غلفاني.
- **تقريب** قطب مغناطيس من وجه الوشيعة ⇒ خطوط الحقل **المحرِّض** ضمن الوشيعة تزداد ⇒ **تدفقه يزداد** ⇒ تنشأ **قوة محركة كهربائية متحرضة `e`** ⇒ تحرك الإلكترونات ⇒ ينشأ **تيار متحرض `i`** ⇒ ينحرف المؤشر.
- **تبعيد** القطب ⇒ التدفق **ينقص** ⇒ `e` ⇒ `i` **باتجاه معاكس** لحالة التقريب.
- **تثبيت** القطب مقابل الوجه ⇒ التدفق **ثابت** ⇒ لا `e` ولا `i` ⇒ المؤشر على الصفر.

> **`e` تظهر فقط ما دام التدفق يتغير.** الحركة النسبية هي المهم (تحريك الوشيعة بدل المغناطيس يعطي النتيجة نفسها).

**قانون فاراداي (نص):** يتولد تيار متحرض في دارة مغلقة إذا **تغيّر** التدفق المغناطيسي الذي يجتازها، ويدوم بدوام تغير التدفق لينعدم عند ثباته.
**قانون لنز (نص):** جهة التيار المتحرض تكون بحيث **ينتج أفعالاً تعاكس السبب** الذي أدى إلى حدوثه.
- **تطبيق لنز [أستاذ طرق حل ٧]:** تقريب قطب ⇒ يتشكل على وجه الوشيعة المقابل **وجه مماثل** (شمالي أمام شمالي ⇒ تنافر يعاكس التقريب) · إبعاد قطب ⇒ **وجه مخالف** (تجاذب يعاكس الإبعاد).

### ٢. العوامل — قانون فاراداي الكمّي [أستاذ س٣ / الكتاب ص ١١٠]
`e` تتناسب **طرداً مع تغير التدفق `ΔΦ`** و**عكساً مع زمن التغير `Δt`**:
> **`e = −ΔΦ/Δt`** (وسطياً) · **`e = −dΦ/dt`** (آنياً)
**الإشارة السالبة** تعبّر عن قانون لنز. التيار المتحرض في دارة مقاومتها `R`: `i = e/R = −(1/R)·dΦ/dt`.

> **⚠️ الخطأ الشائع ١:** «تيار متحرض كبير يعني تدفقاً كبيراً». لا — يعني **تغيراً سريعاً** في التدفق. تدفق هائل ثابت ⇒ صفر تحريض.

### ٣. وشيعتان متقابلتان — لماذا يضيء المصباح بلا اتصال؟ [أستاذ س٢]
الأولى بمنبع **متناوب** وقاطعة، الثانية بمصباح. نغلق القاطعة ⇒ يضيء المصباح.
**التفسير:** المنبع المتناوب (متغير القيمة والجهة) يولّد `B` **متغيراً** في الأولى ⇒ **يتغير تدفقه** في الثانية ⇒ تنشأ `e` ⇒ تيار متحرض ⇒ يضيء. **لزيادة الإضاءة:** نقرّب الوشيعتين، نزيد الشدة، نضع نواة حديدية.
**نستبدل بمنبع مستمر (بيل):** لا يضيء — `B` ثابت ⇒ تدفق ثابت ⇒ لا `e`. **ليضيء:** نفتح ونغلق القاطعة باستمرار، أو نقرّب ونبعد الوشيعتين. **(جواب سؤال التوقّع أ، ب — وهو سؤال الكتاب ص ١٢٤/١ حرفياً.)**

### ٤. التفسير الإلكتروني — السكتان التحريضية [أستاذ س٤ / الكتاب ص ١١١]
**الدارة مغلقة (نشوء `i`):** عند تحريك الساق بسرعة `v⃗` تتحرك إلكتروناتها الحرة بالسرعة نفسها وتخضع ضمن `B` لقوة مغناطيسية `F⃗m = −e·v⃗∧B⃗` على طول الساق ⇒ تدفعها فتنشأ حركة إجمالية ⇒ **تيار متحرض** جهته الاصطلاحية **عكس** حركة الإلكترونات (عكس `F⃗m`). هذا التيار يخضع لقوة **كهرطيسية** (لابلاس) تعاكس حركة الساق (لنز).
**الدارة مفتوحة (نشوء `e`):** القوة المغناطيسية تنقل الإلكترونات إلى أحد طرفي الساق فيصبح **سالباً** والآخر **موجباً** ⇒ فرق كمون بين الطرفين يمثل `e`. **لماذا يتوقف التراكم؟** لأن الشحنات المتراكمة تولّد حقلاً كهربائياً `E⃗` داخل الساق يؤثر في الإلكترونات بقوة كهربائية `F⃗e = −e·E⃗` تعاكس `F⃗m`؛ كلما زاد التراكم زاد `E` وزادت `Fe` حتى تساوي `Fm` فيتوقف الانتقال. (سؤال الكتاب ص ١٢٤/٢.)

## 🧮 البرهان المُرقَّم ١ — مبدأ المولد (ميكانيكية ⇒ كهربائية) [أستاذ س٥ / الكتاب ص ١١٢]
ساق `L` تتحرك بسرعة ثابتة `v ⊥ B` على سكتين، الدارة مغلقة بمقاومة `R`.
| # | | درجة |
|---|---|---|
| ① | في `Δt` تنتقل الساق `Δx = v·Δt` فتمسح `ΔS = L·v·Δt` | ٣ |
| ② | يتغير التدفق `ΔΦ = B·ΔS = B·L·v·Δt` | ٣ |
| ③ | فاراداي: `|e| = ΔΦ/Δt` ⇒ **`e = B·L·v`** | ٤ |
| ④ | التيار المتحرض `i = e/R = BLv/R` | ٣ |
| ⑤ | **الاستطاعة الكهربائية الناتجة** `Pe = e·i = B·L·v·i` | ٣ |
| ⑥ | الساق تخضع لقوة لابلاس `F = i·L·B` **تعاكس** حركتها (لنز) ⇒ لاستمرار الحركة نقدّم قوة مساوية ⇒ **الاستطاعة الميكانيكية المقدمة** `Pm = F·v = i·L·B·v` | ٤ |
| ⑦ | **`Pm = Pe`** ⇒ تحولت الطاقة الميكانيكية إلى كهربائية — **مبدأ المولد** | ٢ |

## 🧮 البرهان المُرقَّم ٢ — مبدأ المحرك (كهربائية ⇒ ميكانيكية) [أستاذ س٦ / الكتاب ص ١١٦]
نمرر تياراً `I` من مولد في الساق الخاضعة لـ`B`.
| # | | |
|---|---|---|
| ① | تنشأ قوة كهرطيسية `F = ILB` تحرك الساق بسرعة `v` ⇒ **الاستطاعة الميكانيكية الناتجة** `Pm = F·v = ILBv` | ٤ |
| ② | بانتقال الساق يتغير التدفق ⇒ تنشأ **قوة محركة متحرضة عكسية** `e′ = BLv` تعاكس تيار المولد (لنز) | ٤ |
| ③ | لاستمرار مرور `I` يجب أن يقدم المولد **استطاعة كهربائية** `Pe = e′·I = BLvI` | ٤ |
| ④ | `Pe = Pm` ⇒ تحولت الكهربائية إلى ميكانيكية — **مبدأ المحرك** | ٢ |

**تجربة المحرك والمصباح [أستاذ س٧]:** نمنع المحرك من الدوران فيضيء المصباح بشدة؛ نسمح له بالدوران ⇒ تزداد سرعته و**تقل إضاءة المصباح**. **لماذا؟** لأنه تنشأ في المحرك `e′` عكسية مضادة لقوة المنبع، تزداد بازدياد سرعة الدوران ⇒ ينقص التيار. **منشؤها:** ملف يدور ضمن `B` ⇒ يتغير تدفقه ⇒ `e′` تتوقف على سرعة الدوران.

### ٥. مولد التيار المتناوب الجيبي [أستاذ س٨ / الكتاب ص ١١٤]
إطار `N` لفة مساحة `S` يدور بسرعة زاوية ثابتة `ω` في `B` منتظم؛ الزاوية بين الناظم و`B⃗`: `α = ω·t` (بفرض `α = 0` عند `t = 0`).
- التدفق: `Φ = N·B·S·cos(ωt)`.
- فاراداي: `e = −dΦ/dt = N·B·S·ω·sin(ωt)` ⇒ **`e = Emax·sin(ωt)`** مع **`Emax = N·B·S·ω`**.
- التيار في دارة مقاومتها `R`: `i = (Emax/R)·sin(ωt) = Imax·sin(ωt)` — **متناوب جيبي**.
- **الخط البياني `e(t)`:** جيبي؛ **موجبة** في النصف الأول من الدور، **سالبة** في الثاني؛ **معدومة** في بداية ومنتصف ونهاية الدور (حيث `Φ` أعظمي!)؛ **عظمى** عند نهاية الربع الأول (`ωt = π/2`، حيث `Φ = 0`).

> **⚠️ الخطأ الشائع ٢:** «`e` عظمى عندما التدفق أعظمي». العكس تماماً — `e` تتبع **سرعة تغير** التدفق؛ عند `Φmax` المشتق صفر.

### ٦. التحريض الذاتي [أستاذ س٩–س١١ / الكتاب ص ١١٨–١٢٠]
**التجربة:** مصباح على التسلسل مع وشيعة ومقاومة معدلة، إضاءته خافتة.
- **لحظة فتح القاطعة:** يتوهج **بشدة** قبل أن ينطفئ. **التفسير:** يتناقص تيار المنبع في الوشيعة حتى ينعدم ⇒ يتناقص `B` الذي تولّده ⇒ **يتناقص تدفقه ضمن الوشيعة ذاتها** ⇒ تنشأ `e` **ذاتية** ⇒ تيار متحرض يمر في المصباح فيتوهج ثم ينطفئ. `e` كبيرة جداً لأن `di/dt` **أكبر ما يمكن** — زمن التناقص متناهٍ في الصغر. **(جواب سؤال التوقّع ج.)**
- **لحظة إغلاق القاطعة:** يتوهج ثم يعود خافتاً. **التفسير:** يزداد تيار المنبع حتى يثبت ⇒ يزداد التدفق الذاتي ⇒ `e` ذاتية ⇒ تيار متحرض **بعكس** تيار المولد؛ عند ثبات التيار تختفي ويعود خافتاً.

**الذاتية `L`:** التدفق الذاتي يتناسب طرداً مع التيار: **`Φ = L·i`**؛ `L` ذاتية الوشيعة، وحدتها **الهنري (H)**: ذاتية وشيعة إذا تغير فيها التدفق ١ Wb تحرّض فيها تياراً ١ A (أو: `1 H = 1 Wb/A`).
**[أستاذ س١٠] `e` الذاتية الآنية:** `e = −dΦ/dt = −d(Li)/dt` ⇒ **`e = −L·di/dt`** — **تنعدم عند ثبات التيار** (`di/dt = 0`).
**ذاتية وشيعة (الكتاب ص ١٢٠):** `Φ = N·B·S = N·μ0·(N/l)·i·S` ⇒ **`L = μ0·N²·S/l`** (تزداد مع مربع اللفات؛ نواة حديدية تضربها بـ`μ`).

### ٧. الطاقة الكهرطيسية المختزنة في الوشيعة [أستاذ س١١ / الكتاب ص ١٢٠]
دارة: مولد `E`، مقاومة `R`، وشيعة `L`؛ التيار يزداد من ٠ إلى `I`.
| # | | |
|---|---|---|
| ① | كيرشوف: `E = R·i + L·di/dt` (الوشيعة تقابل تيار المولد بـ`e = −L di/dt`) | ٤ |
| ② | نضرب بـ`i·dt`: `E·i·dt = R·i²·dt + L·i·di` | ٣ |
| ③ | `E·i·dt` طاقة يقدمها المولد خلال `dt` · `R·i²·dt` ضائعة حرارياً بجول · **`L·i·di` طاقة كهرطيسية تختزنها الوشيعة** | ٣×٢ |
| ④ | نجمع (نكامل) من ٠ إلى `I`: **`EL = ½·L·I²`** | ٤ |

**الخط البياني `i(t)` للتحريض الذاتي (الكتاب ص ١٢٤/٣) [أستاذ]:** `OA` يزداد التيار (لحظة الإغلاق) ⇒ `EL` تزداد · `AB` ثابت ⇒ `EL` ثابتة و`e = 0` · `BC` ينقص (لحظة الفتح) ⇒ `EL` تنقص. **`e` عند الفتح أكبر** من الإغلاق لأن زمن التناقص أقصر.

### ٨. تحديد جهة التيار المتحرض [أستاذ طرق حل ٨]
① نحدد جهة `B⃗` **المتحرض**: **بجهة `B` المحرِّض** عند التبعيد/التناقص، **عكسه** عند التقريب/التزايد. ② نضع إبهام اليد اليمنى بجهة `B⃗` المتحرض ⇒ التفاف الأصابع يشير إلى جهة `i`.
**مثال ملف قرب سلك [أستاذ + الكتاب ص ١٢٤/٥]:** إبعاد الملف ⇒ `B` السلك عنده ينقص ⇒ تدفقه ينقص ⇒ `B` متحرض **بجهة** `B` السلك ⇒ `i` بالاتجاه المناسب (مع عقارب الساعة إذا كان `B` للداخل). تقريب ⇒ العكس. تحريكه **موازياً** للسلك ⇒ `B` ثابت ⇒ لا تيار.

**تحولات الطاقة في المسائل [أستاذ]:** `e·i·Δt` (كهربائية متحرضة) `= R·i²·Δt` (حرارية بجول) — تحولت من كهربائية متحرضة إلى حرارية.

## ✍️ مثال محلول ١ — قطب يقترب من وشيعة [أستاذ طرق حل ١–٩]
وشيعة `N = 500` لفة، `S = 20 cm²`، مقاومتها `R = 10 Ω`. يزداد الحقل عبرها بانتظام من `0` إلى `0.4 T` خلال `0.2 s` بتقريب قطب شمالي عمودياً على وجهها.
| | | |
|---|---|---|
| `ΔΦ` | `ΔΦ = N·S·(B2 − B1)·cos 0 = 500×2×10⁻³×0.4 = 0.4 Wb` | ٥+٣+١+١ |
| `e` | `|e| = ΔΦ/Δt = 0.4/0.2 = 2 V` | ٥+٣+١+١ |
| `i` | `i = e/R = 0.2 A` (دلالة المقياس) | ٥+٣+١+١ |
| جهة `i` | تقريب ⇒ `B` متحرض **عكس** `B` المحرض ⇒ الوجه المقابل **شمالي** (يعاكس التقريب — لنز) ⇒ التيار فيه **عكس** عقارب الساعة بالنسبة للمغناطيس | ٥ |
| الطاقة الحرارية | `Q = R·i²·Δt = 10×0.04×0.2 = 0.08 J` = `e·i·Δt` ✓ | ٥+٣+١+١ |
| **إضافي [أستاذ]:** إبعاد القطب الشمالي | نفس القيم؛ الجهة تنعكس؛ الوجه المقابل **جنوبي** | |

## ✍️ مثال محلول ٢ — وشيعة وتيار متغير (الكتاب ص ١٢٠) [أستاذ طرق حل ١ «نشتق تابع التيار»]
وشيعة `l = 0.5 m`، `N = 1000`، `r = 4 cm`، مقاومتها مهملة. `π² = 10`.
| | | |
|---|---|---|
| الذاتية | `L = μ0·N²·S/l`؛ `S = πr² = 16π×10⁻⁴` ⇒ `L = 4π×10⁻⁷×10⁶×16π×10⁻⁴/0.5 = 128π²×10⁻⁵ ≈ 1.28×10⁻² H` | ٥+٣+١+١ |
| `e` عند تزايد `i` من ٠ إلى `10 A` خلال `0.1 s` | `e = −L·Δi/Δt = −1.28×10⁻²×100 = −1.28 V`؛ التيار المتحرض **يعاكس** التزايد | ٥+٣+١+١ |
| `EL` | `EL = ½·L·I² = ½×1.28×10⁻²×100 = 0.64 J` | ٥+٣+١+١ |
| إذا أُعطي `i = 2t` (تابع) **[أستاذ]** | `e = −L·di/dt = −1.28×10⁻²×2 = −2.56×10⁻² V` ثابتة | |

## ✍️ مثال ٣ — أكمل: المولد الجيبي

- `ω = 2π×50 = ▢ rad·s⁻¹` · `Emax = N·B·S·ω = 100×0.2×0.02×▢ = ▢ V`.
- `e = ▢·sin(100π·t)` · أعظمية عند `t = T/4 = ▢ s`.

**س٥.** نقرّب قطباً جنوبياً من وجه وشيعة؛ الوجه المقابل يصير: **جنوبياً** ✓ (وجه مماثل — تنافر يعاكس التقريب).
**س٦.** لماذا يتوقف تراكم الشحنات في طرفي ساق متحركة بدارة مفتوحة؟ > عندما تتساوى القوة الكهربائية للحقل الناشئ عن الشحنات المتراكمة مع القوة المغناطيسية.
**س٧.** ما الفرق بين مبدأ المولد والمحرك بجملة؟ > المولد: نحرّك الساق فينشأ تيار (`Pm → Pe`)؛ المحرك: نمرر تياراً فتتحرك الساق (`Pe → Pm`)؛ في كليهما تظهر `e = BLv` — متحرضة في الأول، عكسية في الثاني.

## 🧾 خلاصة
| | |
|---|---|
| `e = −dΦ/dt`، `i = e/R` | فاراداي + لنز (الإشارة) |
| تقريب ⇒ وجه مماثل؛ إبعاد ⇒ مخالف | لنز عملياً |
| `e = BLv`، `Pm = Pe = BLvi` | مولد/محرك |
| `Φ = NBS cos ωt` ⇒ `e = NBSω sin ωt` | `Emax = NBSω` |
| `Φ = Li`، `e = −L di/dt`، `L = μ0N²S/l` | H = Wb/A |
| `EL = ½LI²` | تزداد OA، ثابتة AB، تنقص BC |
| جهة `i`: `B` متحرض ⇒ إبهام ⇒ أصابع | **[أستاذ]** |

## ⚖️ خصومات السلم
1. إهمال الإشارة السالبة في `e = −dΦ/dt` عند طلب «القيمة الجبرية».
2. تفسير بلا سلسلة (تيار ⇒ `B` ⇒ `Φ` ⇒ `e` ⇒ `i`).
3. «تنعدم `e` الذاتية» بلا شرط `di/dt = 0`.
4. برهان الطاقة بلا تسمية الحدود الثلاثة.
