# ٣٥ — تصميم وحدة التعلم: دورة الفقرة الكاملة (النواسات)

> **تاريخ:** 2026-10-01 · **الغالب:** hady-albnnai · **المراجعة:** الأستاذ فداء البني
> **الحالة:** قرارات ٧٣–٧٧ معتمدة من المالك (رد مباشر 2026-10-01) · تصميم الشاشة 1 معتمد بصورته (كومِت `51ae7ae`).
> **السياق:** بعد اعتماد معاينة الفقرة 1 (PNG + خط التطبيق + رمزا k/m)، رجع المالك تصميم طريقة العرض بالكامل:
> «كل فقرة بتنتهي شرحها بنحط التجربة الموجودة وبطاقة مراجعة ومثال محلول وسؤال بيتجدد عن طريق الضغط على زر».

## ١. القرارات المعتمدة

| # | القرار | التفاصيل |
|---|--------|----------|
| **٧٣** | **لا توضيحات عمل الميزات للطالب** (قاعدة دائمة — دستور §٥) | الطالب يرى فقط ما يحتاجه: المحتوى + الإجراء. لا نصوص تشرح «وش بتعمل هالزر/هالجزء». التوضيحات للمالك/الأستاذ خارج إطار الهاتف في مستندات المعاينة. |
| **٧٤** | **الوحدة = فكرة منطقية** (مو كل فقرة نصية) | النوط فيها 1565 فقرة قابلة للمراجعة؛ الوحدات ≈ **100 وحدة** (تقسيم يُعتمد وحدة وحدة في صفحة المراجعة). الوحدة الخفيفة تاخذ الحد الأدنى (شرح + بطاقة + سؤال) والثقيلة تاخذ الخمسة كاملة. |
| **٧٥** | **بنية الوحدة (5 أجزاء، بالترتيب المعتمد)** | ١ **الشرح** (نص الأستاذ كما هو + رموز R1–R14 + الأشكال) ← ٢ **بطاقة مراجعة** (استرجاع نشط) ← ٣ **التجربة** (المحاكاة الموجودة بالتطبيق، **إذا كانت موجودة** للوحدة) + **سؤال تنبؤ** قبل التشغيل ← ٤ **المثال المحلول** (من أمثلة الأستاذ) ← ٥ **الاختبار الذاتي**: سؤال يتجدد بالزر «سؤال جديد» ∞. |
| **٧٦** | **الاختبار الذاتي = اختياري (soft)** | ما في بوابة إجبارية بين الوحدات. زر «سؤال جديد» = تمرين لا نهائي (قوالب معاملية). «فهمتها» متاح دائماً. |
| **٧٧** | **طبقة التعليم يلفّها الأستاذ** | نحن نجهز **قوالب فارغة جاهزة للكتابة** لكل وحدة (مخطط JSON تحت)؛ الأستاذ يملأها ويعتمد من عنده مباشرة — بنفس دورة «كل وحدة توصل → موافقة الأستاذ → اعتماد» المتفق عليها. |

**ترتيب ٣ قبل ٤ (تجربة ← مثال) — سبب المالك+التوصية:** الطالب يمسك الحدس من التجربة قبل المعالجة الرياضية، وسؤال التنبؤ يخلي التجربة نشطة مو مشاهدة سلبية (PhET: التنبؤ ثم التحقق > الاستكشاف الأعمى؛ المشاهدة السلبية ما بتعلم).

## ٢. مخطط قالب الوحدة (ما يملأه الأستاذ)

```jsonc
// unit-0001.json — قالب فارغ، الأستاذ يملأ الحقول
{
  "unit_id": "U1-01",
  "section": "النواس المرن",
  "title": "النواس المرن الغير متخامد",          // من نص النوط
  "source_blocks": [5, 6],                        // بلوكات text.json (آلي)
  "figure": "F0002",                              // الشكل من أصول النوط (آلي)
  "cards": [                                      // ٢–٤ بطاقات مراجعة
    { "front": "مركز الاهتزاز", "back": "النقطة الثابتة التي يهتز الجسم إلى جانبيها" }
    // الأستاذ يضيف/يعدل — نجهز اقتراحات أولية من تعريفات الأستاذ (لا تُعتمد من عندنا)
  ],
  "experiment": {                                 // null إذا ما فيه تجربة للوحدة
    "sim": "spring-oscillator",                   // محاكاة موجودة بالتطبيق
    "prediction": {
      "q": "إذا ضاعفنا الكتلة، شو يصير بالزمن الدوري؟",
      "choices": ["يتضاعف", "ينقص للنصف", "ما يتغير", "ما أدري"]
    }
  },
  "example": {                                    // مثال محلول — من أمثلة الأستاذ حرفياً
    "problem": "نابض صلابته k = 20 N/m معلق فيه جسم كتلته m = 0.5 kg. احسب الزمن الدوري T.",
    "solution_steps": ["T = 2π√(m/k)", "T = 2π√(0.5/20)", "T ≈ 0.99 s"]
  },
  "question_templates": [                         // قوالب متجددة: المعطيات بتتبدل، المنطق ثابت
    {
      "kind": "numeric",
      "stem": "نابض صلابته {k} N/m تحمل كتلة {m} kg — الزمن الدوري؟",
      "params": { "k": [4, 8, 12, 20], "m": [0.2, 0.5, 1, 2] },
      "answer_fn": "T = 2*PI*sqrt(m/k)",
      "distractors": "auto"                        // توليد أخطاء شائعة (√ بالعكس، إهمال 2π…)
    }
  ]
}
```

**قواعد التوليد (٧٥/٧٦):** كل ضغطة «سؤال جديد» = سحب معاملات جديدة من `params` + إعادة خلط الخيارات. مسائل النواسات كلها معاملية (m, k, A, θ, g) → قالب واحد يغطي عشرات المتغيرات بلا كتابة يدوية.

## ٣. التأثير على خط التفريغ (docs/34)

| المرحلة | قبل | بعد |
|---------|------|------|
| A | تفريغ النوط ← `pack.json` | A1: المحتوى (كما هو) + **A2: قوالب طبقة التعليم فارغة لكل وحدة** (باقتراحات أولية غير معتمدة) |
| B (مراجعة) | صفحة المراجعة الحالية (1565 بلوك) | **v2 على مستوى الوحدة**: كل وحدة = شرح + بطاقات + تجربة + مثال + قوالب أسئلة، مع **حقل مملوء/فارغ** للأستاذ + اعتماد |
| C | `pack.json` | + حقول `cards / experiment / example / question_templates` + حالة `approved_by_teacher` |
| D | الشاشات | شاشة الوحدة = 5 أجزاء بترتيب ٧٥ (شاشة 1 = الشرح معتمدة `51ae7ae`) |

**لا تأثير** على: نص المادة (كما هو حرفياً — قرار المصدر النهائي)، رموز R1–R14، صفحة المراجعة الحالية (تظل صالحة للبلوكات؛ v2 بنية إضافية فوقها).
