## قواعد التصنيف (تُطبق أثناء التأليف)

1. **تجربة (ج):** فقط عندما توجد محاكاة مناسبة بالتطبيق: نابض (1.2، 1.3)، فتل (2.3)، مركب (4.5)، بسيط (5.5)، رنين (7.12). وحدة بدون محاكاة = جزء يتخطى (قرار ٧٥).
2. **مثال محلول (م):** من أمثلة الأستاذ **حرفياً** (R1–R14 فقط) — كل وحدة فيها مثال بالنوط تاخذ م.
3. **قالب سؤال (س):** مسائل عددية (دور، سعة، زمن، طاقة، عزم) = قالب معاملية متجددة. مفاهيم = بنك خيارات (2–4 متغيرات).
4. **بطاقة (ب):** من التعريفات والملاحظات فقط (مصطلح ↔ تعريف) — 2–4 بطاقات/وحدة.
5. **الوحدة الخفيفة:** شرح + بطاقة + سؤال فقط (الوحدات المفاهيمية الصغيرة).
6. كل وحدة = 1–3 شاشات بالتطبيق حسب حجم المحتوى.
