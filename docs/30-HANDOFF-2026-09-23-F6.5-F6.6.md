## ١. F6.5 — شاشة الشهادة (مدموجة، `main`=`ac74564`)

**ما أُضيف:**
- `app/lib/features/account/certificate_screen.dart` (جديد): بطاقة رسمية —
  الطبقة (🥇 سنتان / 🥈 سنة) + العنوان «بطل دوري فيزيا كلاش» + الموسم + السنوات
  + النقاط + شارة «موثّقة». زر «نسخ/مشاركة» عبر `Clipboard` (بلا اعتمادية جديدة).
  حالات صريحة بمفاتيح اختبار: `SEASON_OPEN` · `NOT_PARTICIPATED` ·
  `BAD_LOCAL_SIGNATURE` · لا اتصال (+ إعادة) · خطأ عام.
- `app/lib/core/supabase/cert_api.dart` (جديد): `CertIssuer` (تجريد) +
  `CertApi` (يبني `challenge_sig` بمفتاح `XpSigner`، ينادي `cert_issue`،
  ثم **يتحقق `verifyEmbedded` إلزاميًّا**) + `LazyCertApi` (تحميل الموقّع كسولًا).
- `certificate.dart`: `currentSeason()` — **مرآة حرفية** لدالة `current_season()`
  الخادمية (0011): الموسم يبدأ ١ أيلول بتوقيت دمشق، صيغته `YYYY-(YYYY+1)`.
- `xp_ledger.dart` + `streak_service.dart`: كشف `signer()` (نفس مفتاح XP؛ لا يخرج
  المفتاح الخاص من الخزنة الآمنة).
- `account_screen.dart`: مدخل «شهادة الموسم» (يظهر عند حقن `CertApi`+`season`).
- `app_shell.dart` + `main.dart`: توصيل `LazyCertApi` وتمرير `currentSeason()`.

**اختبارات:** `certificate_screen_test.dart` (٨) + `current_season_test.dart` (٥).

**عقد العميل↔الخادم** (مرجع سريع): `POST cert_issue`
`{season, device_pubkey_b64, challenge_sig}` مع `Authorization: Bearer <anon>` ⇒
`{ok:true, certificate:{…}}` أو `{ok:false,error:CODE}`/HTTP≥400. التحدّي =
`cert-issue-v1|<season>|<pubkey>` موقّعًا ببايتاته الخام.

## ٢. F6.6 — إدارة نهاية الموسم (فرع `feature/f6.6-season-admin`=`e3edc52`)

**لماذا:** إغلاق الموسم (`seasons.ends_on` يمضي) هو **الشرط الذي يفتح إصدار
الشهادات** في `cert_issue`. لم تكن هناك طريقة لإغلاقه من التطبيق ⇒ أُضيفت للمكتب.

**الملفات (٥):**
| ملف | التغيير |
|-----|---------|
| `supabase/functions/office_codes/index.ts` | فعلان: `season_get` (حالة الموسم) و`season_set` (upsert `ends_on`، تحقق تاريخ صارم `YYYY-MM-DD`، تدقيق في `office_audit`). |
| `supabase/migrations/0016_office_audit_season.sql` | توسيع قيد `office_audit_action_check` ليقبل `'season_set'` (كان generate/revoke فقط). إعادة التشغيل آمنة. |
| `app/lib/core/supabase/office_api.dart` | نموذج `SeasonInfo` + `seasonInfo()` / `setSeasonEnd()`. |
| `app/lib/features/admin/admin_screen.dart` | بطاقة «دوري الموسم»: حالة (مفتوح/ينتهي/مغلق ✅) + تحديد/تعديل تاريخ (DatePicker) + إعادة فتح. تعميم `_confirm` بـ`confirmLabel`. |
| `app/test/season_admin_test.dart` | ٣ حالات: مفتوح · مغلق (تاريخ ماضٍ) · إعادة فتح. |

**السلوك:** `ends_on='YYYY-MM-DD'` يضبط الإغلاق · `null` يعيد الفتح.
`closed = ends_on موجود وقد مضى` (نفس البوابة في `cert_issue`).
الحماية: ترويسة `x-office-key` (كبقية أفعال `office_codes`) — لا JWT.

**اختبارات:** الفحوصات نجحت على جهاز المالك (analyze + test) قبل الدفع.

بعد **دمج** F6.6 في `main` (بكلمة «ادمج»)، ولتفعيل الميزة حيًّا:

```
# ٢) نشر الدالة (تستورد _shared ⇒ CLI حصرًا، لا الداشبورد)

```

## ٥. قواعد أُكِّدت هذه الجلسة
- **الدمج في `main` بكلمة «ادمج» حصرًا** · خطوة واحدة كل مرّة.
- **لا قيم سرّية بالشات ولا بالملفات** · فحص أسرار قبل كل إيداع · إضافة صريحة
  بالمسارات (لا `git add -A`).
- **الدوال المستوردة لـ`_shared` تُنشر بالـCLI حصرًا** (`office_codes` منها).
- **لا كتاب/نوطات على مساحة عمل الوكيل** — الاستنساخ يقتصر على `app`+`supabase`
  (+`docs` عند الحاجة للتوثيق).
- **تنبيه بيئي:** إعدادات `.git` (الرِيموت/الهوية) لا تُحفظ بين الأدوار ⇒ تُعاد
  عند كل دفع.
