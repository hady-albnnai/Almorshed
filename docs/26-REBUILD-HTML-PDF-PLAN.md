## ٦. قواعد البناء الفني (NHTML-2/3)

- `<html lang="ar" dir="rtl">`، والعربية `rtl` داخل `<main dir="rtl" lang="ar">`.
- المعادلات والرموز المختلطة داخل حاوية `dir="ltr"` مع `unicode-bidi: isolate`، واستخدام `<bdi>` عند الحاجة — **لا** `bidi-override` على النص العربي العام.
- كل رسم داخل `<figure>` متمركز، بلا `float` وبلا `position: absolute`، وبلا أكثر من عنصر كبير في طبقة مطلقة.
- `@page { size: A4 portrait; margin: 18mm 15mm 18mm 15mm; }`
- كسر الصفحات: `h1,h2,h3 { break-after: avoid }` و`figure, img, .equation, .question, .table-wrapper { break-inside: avoid }` و`p { orphans: 3; widows: 3 }`.
- الرسم العريض: حاوية مستقلة مع `overflow: visible` وبلا تكبير فوق مساحة الصفحة.
- تصدير PDF: `page.pdf({format:"A4", printBackground:true, preferCSSPageSize:true})` مع انتظار الخطوط والصور — **لا** لقطة شاشة بديلاً عن PDF.
